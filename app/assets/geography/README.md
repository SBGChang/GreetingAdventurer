# 十六城與四國輿圖

這是呈現層的 Blender 美術資料，不建立城市、通行權、旅費或旅行天數。城市名稱與文化歸屬沿用四國正式設計；地形、視覺座標及道路折點是本次新增的美術設計。所有道路與雲京—星井渡湖線均以 `routeId` 對應正式 Content Pack；湖面虛線表示乘船航段。

各城均保留十個 `facility` 根節點與不可互動的 `scenery` 街坊。住宅先避開設施、岩壁與文化地標再配置；樹木避開功能建築與地標。階台建築按完整占地抬高並補基座。正式城鎮只有 GameView 提供的設施可互動；圖鑑預覽不發送遊戲指令。十六城均可旅行；其他十二城目前只開放城門與住宿，文化專屬遊戲內容仍待完成。

街區的正式美術配置在 [town-neighbourhoods.py](../../../scripts/blender/town-neighbourhoods.py)：每城各有街巷主線、街區名稱、住宅組合與公共空間；住宅面向自己的巷道，次巷補入同街區的內側住家。占地檢查保留庭院、地標、乾岸、階台與峽谷引道，配置完成後再將入口接回公共街網。雲京沿用三岸水道街路，赤帆沿用驛道／市集骨架並改為錯落的四組住宅院落，其他十四城由實際入口求出相連道路。

建築使用九種實際空間結構：附翼長屋、開放三合院、工坊工作院、並列店屋、塔式住家、架空騎樓、錯層雙屋、架高穀倉與帶菜圃的小屋；不同屋翼有各自屋頂、門窗、柱架及支承。公共建築使用較大尺度的院落、騎樓與店面。近景瓦作、木石作及市集由 [town-craft.py](../../../scripts/blender/town-craft.py)、[薩菲爾雕拱建築](../../../scripts/blender/redsail-detail.py)與[赤帆生活物件](../../../scripts/blender/redsail-life.py)提供；市場棚架的寬深、高度、曲面與貨物各自不同。私人院地、公共鋪路及草地／雪地／沙地使用不同材質與固定比例 UV。這些生活物件不產生遊戲商品或 NPC 行為。

## 大地圖

城內基礎設施由 [town-infrastructure.py](../../../scripts/blender/town-infrastructure.py) 共用橋梁結構、城門方向與城牆開口。側門沿東西方向穿牆，北／南門沿南北方向穿牆；木柵與表面砌石不得重新封住開口。霜灣、澄浦的西側工作岸保留乾地建築與鹽場，白崖港保持水面出口；赭階橋有兩側下橋階梯，冰鑿採石台有岩床支承及上層平台。靠山的北門保留山口引道，中央水池、鹽池、農田與峽谷周圍的道路繞開地景。

依[世界地理契約](../../../docs/01_world/worldbuilding.md#四國十六城與海陸配置)，各文化一座主堡與三座小城。四國位於一片連續大陸，雲華與薩菲爾間為雲星大湖；沿岸道路與湖上航線分開建模。城市縮景保留整城布局、城牆與街坊，主堡寬度 26、小城 20 個美術單位；每座城的建築採約 10,000 三角面減面目標，地基、階台與街道保留原始結構；城垣保留 35% 面數，以較溫和的減面保存牆體輪廓。減面後的頂點限制在原始建築邊界內，避免小型曲面被外插成穿入地面的尖角。地表使用少於 24,000 頂點的裁切三角網格，呈現各區坡地、支脈與山谷，微細節沿用 UV 材質。

開圖預設聚焦玩家所在地；選城聚焦附近，左鍵拖曳巡覽、右鍵旋轉、滾輪縮放。「全圖總覽」查看大陸、內陸湖與十六城，「回到所在地」恢復區域視野。鏡頭參數記於 atlas.json 的 camera。

[world.blend](world.blend) 與 [world.glb](world.glb) 包含海面、立體陸塊、連續山脊、雪地、森林、河流、沙地、城市縮景與道路。地表採精簡網格搭配 [UV 顏色與法線材質](materials.md)，海岸使用連續輪廓，岩層紋理與地表微細節不靠增加幾何。東方雲華、西方奧瑞恩、北方維爾冬、南方薩菲爾。城市的 `cityKey` 根節點供射線選取與名稱投影使用；UI 文字不烘焙到模型。

[atlas.json](atlas.json) 是美術布局來源，列出模型引用、名稱、文化、城市視覺座標與道路折點。十六城均帶正式 `cityId`，使用世界節點 ID；旅行拓樸由 `content-source/world-network.ts` 與雲華作者資料提供。遊戲旅行選項仍由 `city.neighbours` 與 `city.travelModes` 決定，不根據本圖的距離或道路標記推算。

## 重建與檢查

共用近景貼圖改動後，先以 Blender 執行 [bake-town-craft.py](../../../scripts/blender/bake-town-craft.py) 重建法線，再執行各城建模入口。共用材質與提示詞見[材質契約](materials.md)。城牆的表面裝飾放在獨立 `Masonry surface detail` 根節點，完整城市保留細節，世界縮景對裝飾減面並保留原有結構。

使用 Blender 背景模式執行 [build-geography.py](../../../scripts/blender/build-geography.py)，產生十五座城池與大地圖的 `.blend`、`.glb`、`.png`。可在 `--` 後列指定城市 key（例如 `qingcen`）；城市完成後，以另一個 Blender 背景程序執行 `-- world`，避免從目前開啟的同一份 `.blend` 匯入自身。路面更新相容入口為 `-- paving qingcen chengpu`：路面、庭院與立面已共用精修流程，因此會完整重建指定城市，再輸出模型與渲染圖。雲京仍由 [build-town.py](../../../scripts/blender/build-town.py) 重建；新建模腳本共用其中的建築基礎函式；大地圖由 [world-surface.py](../../../scripts/blender/world-surface.py) 處理，舊的大色塊與錐體山脈建模已移除。

模型輸出後，以 Blender `--background --python-exit-code 1 --python scripts/blender/verify-clearance.py` 執行[幾何與通道檢查](../../../scripts/blender/verify-clearance.py)。它檢查十六城的獨立建築、公共廣場與外部景物、大地圖城市與環境的交叉，並沿實際模型射線檢查三座雲京橋的乾地落點與橋面、三十二處城門通道、兩座港城的十六處建築地基、赭階橋及青岑兩段階梯。十四城的新街網另逐面取樣，檢查建築不得占住行走空間、入口須接近實際鋪路；不只信任根節點的連通標記。同棟建築的結構接合不算穿模。這是空間驗收，不是 NPC 行人模擬。結果與受檢 `.blend`／`.glb` 的 SHA-256 寫入 `geometry-clearance.json`，修改模型後必須重新檢查。

`npm run verify:geography` 驗證上述結果與模型雜湊一致，並檢查模型各自不同、十種地標、街坊、世界城市標記與全部正式路線一致，並檢查連通陸地與封閉湖岸。`npm run verify:atlas` 使用隔離桌面存檔查看十六城，檢查預覽不改動進度，並實際抵達全部十六城、跨湖與跨國、重載存檔及驗證地標射線選取。
