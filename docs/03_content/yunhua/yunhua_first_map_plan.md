# 雲華第一版可探索地圖

> 第一版只開放雲華兩座城市與三張可探索地圖。每座城市原則上一張地圖；首都雲京額外擁有一張國家迷宮。

## 共通規則

- 黑格：不存在地塊；藍格：入口；紅格：出口；白格：一般可行走地塊。入口與出口皆為獨立單格房間。
- 相鄰格之間的白色開口代表通道；紅線代表門；兩者皆無則不能通行。
- 相鄰小格之間完全沒有牆線，代表它們合併為同一個房間，不是通道開口；房間可為 L、T、凹形等任意形狀，不必是 1×1。
- 每個房間才是一個可選擇的移動節點；房內沒有移動。移動到相鄰房間時，疲勞才依房間覆蓋的實際小格數計算。
- `↑`、`↓` 分別代表上、下樓梯。黃色圈為寶箱偏好房間，藍色圈為事件偏好房間，綠色圈為大型**體型**敵人偏好房間，紅色圈為固定陷阱房間；所有圖示皆屬於該房間，不另形成一格。
- 入口、出口、樓梯與固定陷阱是互斥的單格功能房間：不得與怪物、寶箱、事件或其他功能共存。每個探索地圖合計有 1～3 個出口。
- 相連樓層的同一段樓梯，必須落在完全相同的列、行座標；因此小地圖能辨認上下關係，並允許玩家透過下層繞至同層不相連的區域。
- 一般敵人不使用偏好格，可動態生成在任何允許的普通可通行格。物品、事件與大型體型敵人才依偏好房間生成；偏好房間只限制體型，不指定怪物種類或威脅等級。
- 事件偏好格必須位於至少 2 格組成的中型房間；大型體型敵人偏好房間必須位於長、寬皆至少 2 格的大房間。此處的房間大小是探索地圖條件，與戰鬥九宮格中的敵人體型（大型＝3×3）不同。

## 地圖配置摘要

### 霧篁藥谷

- 單層 8×8；西南入口、東北出口。
- 主路由竹林岔道與架高棧道向北延伸；兩個支線放置寶箱偏好格。
- 中央空地是大型體型敵人偏好房間；瘴氣與落穴為固定陷阱。

### 舊漕渠與沉倉

- 地上層由首都水道入口進入，沿倉房、水閘與拖運軌抵達下行樓梯。
- 地上東側沉倉與入口區沒有同層通道；最深處設為事件偏好格。玩家必須由西側樓梯下至地下蓄水池、橫越暗渠，再由同座標的東側樓梯回到地上，才能抵達這個事件位置。
- 地下一層由蓄水池、暗渠與沉貨區構成，水門出口設在最深處。
- 寶箱偏好格集中於倉架與沉貨區；大型體型敵人只可置於寬廣的閘室。

### 天衡印塔

- 建築型國家迷宮固定 6×6，使用塔 1–4F 與地下 1–2F；所有上下樓梯皆對齊同一座標。
- 塔一層自入口分出上行與下行支線；兩個地下層是封印庫與地脈室的可選探索支線。
- 二、三層依序為校印廊與藏卷層，四層為觀印台；最高層出口代表完成本次國家迷宮探索。
- 大型體型敵人偏好房間只放在四層觀印台的 2×2 大房間；事件偏好格皆放在至少兩格組成的房間。符印陷阱與門的位置固定，讓地圖邏輯可被記憶。
