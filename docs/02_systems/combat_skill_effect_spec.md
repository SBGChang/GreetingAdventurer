# 戰鬥技能與裝備效果規格（第一版）

> 本文件定義戰鬥技能、反擊架勢與裝備效果的觸發方式。它是裝備係數與國別內容的共同規格。

## 核心原則

- 戰鬥中**沒有普通攻擊**；任何攻擊、格擋、施法、演奏、移動或支援行為都必須由玩家選擇一個技能執行。
- 裝備不應以「普攻後」作為觸發條件。裝備提供常駐係數，或修改符合條件的技能與狀態。
- 技能分類是內部資料欄位，不必以大量 Tag 形式顯示給玩家；玩家介面只需顯示需求與類型。

## 技能資料欄位

每個技能至少記錄以下欄位：

| 欄位 | 範例 | 用途 |
|---|---|---|
| 啟動手別 | 主手／副手／雙手同時／無手別 | 決定哪件武器的效果可觸發。 |
| 武器需求 | 單手刀劍／長柄／盾牌／雙手法杖／弦樂器等 | 決定技能能否放入目前武器組。 |
| 行為類型 | 攻擊／格擋／施法／演奏／移動／支援 | 對接 CTB 狀態與裝備效果。 |
| 技術分類 | 斬擊／突刺／反擊／蓄力／位移／符印等 | 供少數裝備做更精準的觸發。 |
| 目標與距離 | 自身／單體／區域；近／中／遠 | 決定站位與地城格局互動。 |

## 反擊技：主動建立、條件結算

反擊技不是常駐被動，也不會免費自動出手。

1. 玩家在自己的 CTB 行動時主動選擇反擊技。
2. 技能消耗行動與疲勞，使角色進入藍色的格擋／反擊架勢。
3. 架勢期間若符合條件，例如敵人以近戰技能攻擊、角色成功格擋，系統立即結算該反擊技。
4. 結算後架勢解除；若條件未發生、格擋失敗、被硬直，則反擊不結算。

反擊技的平衡來源是：預先花行動、可能落空、受攻擊種類限制，以及反擊後的行動延遲或疲勞代價。

## 裝備效果觸發層級

| 層級 | 使用範圍 | 範例 |
|---|---|---|
| 常駐係數 | 所有啟用中的武器組 | 武器的物理傷害係數；盾牌的格擋減傷。 |
| 技能分類觸發 | 一般裝備的主要做法 | 「使用主手單手刀劍的反擊技能，成功格擋後提高格擋壓力。」 |
| 特定技能觸發 | 傳說／神話裝備 | 「只在使用『挑腕』時，追加破甲。」 |
| 狀態／事件觸發 | 依戰鬥結果判定 | 「成功格擋後」「目標硬直時」「完成施法時」。 |

預設優先使用「技能分類觸發」；只有需要明確塑造具名招式時，才使用「特定技能觸發」。

## 雙持與盾牌

| 技能啟動方式 | 可觸發的裝備效果 |
|---|---|
| 主手技能 | 主手武器的常駐與技能觸發效果。 |
| 副手技能 | 副手武器的常駐與技能觸發效果。 |
| 雙手同時技能 | 兩手武器都提供既有持握係數；效果分別判定。相同控制類效果不疊加，只取最強者。 |
| 盾牌技能 | 盾牌的格擋、盾擊、掩護等效果可觸發。 |
| 非盾牌技能 | 盾牌常駐防護有效；不觸發「盾擊」等盾牌專用效果。 |

切換武器組後，只有目前武器組的常駐係數與觸發效果有效。

## 裝備效果撰寫格式

```text
青紋長刀
常駐：物理傷害與命中係數。
條件：使用 [主手・單手刀劍・反擊] 技能，且成功格擋。
效果：提高該反擊技能的格擋壓力。
限制：不適用於副手、匕首、扇子、法杖或非反擊技能。
```
