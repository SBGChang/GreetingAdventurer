# 戰鬥技能與裝備效果規格（第一版）

> 本文件定義戰鬥技能、反擊架勢與裝備效果的觸發方式。它是裝備係數與國別內容的共同規格。

## 核心原則

- 戰鬥中**沒有普通攻擊**；任何攻擊、格擋、施法、演奏或支援行為都必須由玩家選擇一個技能執行。
- 戰鬥中不存在自主移動、移動技能、推拉或擊退。格位只會在一側第 1 排全空時，由系統把該側所有仍占格單位同步向前補位。
- 裝備不應以「普攻後」作為觸發條件。裝備提供常駐係數，或修改符合條件的技能與狀態。
- 技能分類是內部資料欄位，不必以大量 Tag 形式顯示給玩家；玩家介面只需顯示需求與類型。

## 技能資料欄位

每個技能至少記錄以下欄位：

| 欄位 | 範例 | 用途 |
|---|---|---|
| 啟動手別 | 主手／副手／雙手同時／無手別 | 決定哪件武器的效果可觸發。 |
| 武器需求 | 單手刀劍／長柄／盾牌／雙手法杖／弦樂器等 | 決定技能能否放入目前武器組。 |
| 行為類型 | 攻擊／格擋／施法／演奏／支援 | 對接 CTB 狀態與裝備效果。 |
| 技術分類 | 斬擊／突刺／反擊／蓄力／符印等 | 供少數裝備做更精準的觸發。 |
| 目標形狀 | 自身／單體／區域 | 由 targeting resolver 決定範圍、形狀、人數上限（皆為資料）。 |
| 額外距離 | 多數招式 0；魔法／治療 +6 | 疊加在武器射程上，決定觸及的排距（見「射程與距離」）。 |

## 射程與距離（定案）

戰鬥不移動；「打不打得到」由**射程（格數）**與**施展當下的真實排距**共同決定。

- **武器射程（格數）**：一般近戰 1／雙手・長柄 2／射擊 4–6／施法用具 1（魔法的距離靠招式補正，見下）。
- **招式額外距離**：多數招式為 0；**魔法與治療招式一律 +6**（因此全場可及）。
- **有效射程 ＝ 武器射程 ＋ 招式額外距離**。怪物沒有武器組，改用天生攻擊檔的射程格數。
- **施展距離（只看排、不管左右，從自己 0 起算）**：`距離 ＝ 攻方離己方前排排數 ＋ 守方離己方前排排數`。
  **自己所在那一格是 0**：前排對前排 ＝ 0；前排打敵方第 2 排 ＝ 1；後排打敵方前排 ＝ 2；雙方後排 ＝ 4（最遠）。
  左右完全不影響（右後、左後打敵左前都是 2）。大體型目標取其最前佔用排。

  距離從 0 起算是射程才有意義的前提：**一般近戰（射程 1）站前排打得到敵方第 1、2 排**（距離 0 與 1）；
  雙手・長柄（射程 2）從前排涵蓋整個敵陣；後排的近戰只打得到敵方前兩排以內。
  （舊版多了 `＋ 1`，使得射程 1 的近戰只打得到敵方前排一排，與本節設計意圖不符，已訂正。）
- **合法目標**：`距離 ≤ 有效射程`，超過就打不到。範圍／形狀／人數仍由 targeting resolver 決定，射程只是
  額外的合法性過濾。因此**不再有「近／中／遠」三種招式分類**——距離能力來自武器（與招式加成），不是招式類別。

這讓「保持站位格數」有實際意義：近戰被鎖在前排（距離短），遠程／魔法能站後排安全輸出，但要付距離代價（見下）。

## 命中、迴避與格擋（沿用副屬性與平衡模型公式）

命中不是憑空的基礎值，而是**攻方命中副屬 對抗 守方迴避副屬**；格擋是守方格擋副屬的第二道判定。
命中／魔法命中／迴避／格擋等副屬由 derived-statistics 從主屬＋裝備＋熟練度＋狀態算成「分數」。

- **命中率** ＝ `clamp(15, 95, 70 + (命中分數 − 迴避分數) × 0.25)`（分數不是百分比）。未命中：不套該次傷害，
  但仍付出行動與 CTB（攻擊會落空）。
- **格擋成功率** ＝ `clamp(0, 75, 格擋分數 × 0.25)`，且仍須守勢／技能條件允許（不是常駐免傷）；成功格擋才套
  **格擋吸收** `raw/(raw+80)`。成功格擋也是反擊架勢的結算條件之一（見下節）。
- **一般／魔法減傷** ＝ `raw/(raw+120)`（raw 先夾在 0 以上）。
- **傷害本體** ＝ `Σ(主屬 × 裝備係數) × Mastery係數 × 技能威力`（物傷肌＋協、魔傷智、樂器智＋協＋魅）。

## 距離修正（第一版數值，待討論）

距離除了決定「打不打得到」，也影響**傷害、命中、CTB**：**距離 2 為標準（×1.0）**，越近越有利、越遠越不利。
獎勵刻意壓小；遠距的代價**主要落在命中變差**（打不準）而非狂砍傷害。命中補正以 **raw 加減**加在攻方命中分數上
（與狀態同機制），補正後的分數才進上面的命中率公式。

| 施展距離 | 0 | 1 | 2（標準） | 3 | 4 |
|---|---|---|---|---|---|
| 傷害 × | 1.1 | 1.05 | 1.0 | 0.85 | 0.7 |
| 命中 raw ± | 近距小幅 ＋ | | 0 | | 遠距較大 − |
| CTB × | 0.9 | 0.95 | 1.0 | 1.15 | 1.3 |

> 距離修正、命中 raw 幅度、以及命中／格擋公式裡我方**新增**的部分屬第一版方案，實際值集中於
> `docs/02_systems/first_version_design_ledger.html`（公式 vs 我設計的數值），可調。命中／迴避／格擋／減傷
> 的公式本體沿用既有平衡模型，不是新發明。

## 反擊技：主動建立、條件結算

反擊技不是常駐被動，也不會免費自動出手。

1. 玩家在自己的 CTB 行動時主動選擇反擊技。
2. 技能消耗行動，使角色進入藍色的格擋／反擊架勢。
3. 架勢期間若符合條件，例如敵人以近戰技能攻擊、角色成功格擋，系統立即結算該反擊技。
4. 結算後架勢解除；若條件未發生、格擋失敗、被硬直，則反擊不結算。

反擊技的平衡來源是：預先花行動、可能落空、受攻擊種類限制，以及反擊後的行動延遲代價。

## 裝備效果觸發層級

| 層級 | 使用範圍 | 範例 |
|---|---|---|
| 常駐係數 | 所有啟用中的武器組 | 武器的物理傷害係數；盾牌的格擋減傷。 |
| 技能分類觸發 | 一般裝備的主要做法 | 「使用主手單手刀劍的反擊技能，成功格擋後提高格擋壓力。」 |
| 特定技能觸發 | 傳說／神話裝備 | 「只在使用『挑腕』時，追加破甲。」 |
| 狀態／事件觸發 | 依戰鬥結果判定 | 「成功格擋後」「目標硬直時」「完成施法時」。 |

預設優先使用「技能分類觸發」；只有需要明確塑造具名招式時，才使用「特定技能觸發」。

## 雙持與盾牌

| 技能啟動方式 | 可觸發的裝備效果 |
|---|---|
| 主手技能 | 主手武器的常駐與技能觸發效果。 |
| 副手技能 | 副手武器的常駐與技能觸發效果。 |
| 雙手同時技能 | 兩手武器都提供既有持握係數；效果分別判定。相同控制類效果不疊加，只取最強者。 |
| 盾牌技能 | 盾牌的格擋、盾擊、掩護等效果可觸發。 |
| 非盾牌技能 | 盾牌常駐防護有效；不觸發「盾擊」等盾牌專用效果。 |

切換武器組後，只有目前武器組的常駐係數與觸發效果有效。

## 裝備效果撰寫格式

```text
青紋長刀
常駐：物理傷害與命中係數。
條件：使用 [主手・單手刀劍・反擊] 技能，且成功格擋。
效果：提高該反擊技能的格擋壓力。
限制：不適用於副手、匕首、扇子、法杖或非反擊技能。
```
