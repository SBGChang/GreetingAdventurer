# 物品系統設計

> 本文件獨立於裝備、技能與道具表。核心目標：讓「物件本身」成為委託、運送、購買、探索與房屋經營的內容來源。

## 物品總分類

```text
物品
├─ 使用道具
│  ├─ 戰鬥消耗道具
│  └─ 非戰鬥消耗道具
├─ 非使用道具
│  ├─ 商品與材料
│  ├─ 珍品與收藏品
│  ├─ 家具與居住物件
│  ├─ 文書、紙本與媒介
│  └─ 事件物件
└─ 裝備
```

## 非使用道具

非使用道具不具有「使用延遲」，因為它們不是戰鬥按鍵或消耗品。它們可被攜帶、堆放、展示、交易、運送、交付或作為材料；第一版不設鑑定、真偽、贓物、損壞、修復或易碎系統。

### 共通資料欄位

| 欄位 | 用途 |
|---|---|
| 類別 | 決定可用於哪些委託、商店與未來房屋系統。 |
| 產地／文化 | 讓四國商品、收藏與運送目標有差異。 |
| 單位重量 | 所有物品都具有固定重量；角色攜帶採重量上限，堆疊物的總重為單位重量乘以數量。上限由肌力計算，不使用格子或體積。 |
| 原價值 | 物件不受市場修正的基準價；內部競拍最低出價使用此值，流標直售為此值的 80%。商店實際價格可再套用市場規則，兩者都不等於委託報酬。 |

### 超載處理

- 角色可因取得物品或攜帶上限下降而短暫超載；玩家隊會立即進入不可關閉的處理畫面，不能繼續其他行動。
- 玩家只能把一般物品贈與仍有容量的正式隊友、在目前城市且自己有房屋時移入自宅倉庫，或直接遺棄。每次操作後重新計算，直到全隊都不超載。
- 旅行途中不彈出處理畫面，只登記延後檢查；抵達後仍超載才強制處理。
- 任務貨物可改派正式攜帶者但不能放入房屋或變成隊友私產；若在強制超載處理中遺棄，必須同步解除任務保留並永久移除，對應任務不新增失敗狀態，仍於期限到達時轉為到期。

## 固定採集點與物品實體

- 採集點是地圖模板固定來源，不是預先生成的一批隱藏 Item Instance。
- 同一 Map Version 每個節點只能成功一次；採集成功時，才依隊伍最高採集等級與 Gathering Rule 解析產物種類、數量並建立正式物品。
- 地牢採集產物先進入本次 Asset Distribution Escrow，採集者不自動成為 Owner；玩家離場競拍、NPC RNG 分配完成後才進入個人背包。
- 未採集節點在地圖刷新時只恢復可採，不會把「尚未生成的資源」轉入城市永久庫存。
- 已採得的物品與一般 Item Instance 完全相同，可在分配後交易、製作或被日後委託指定；地圖刷新不影響它們。

## 與世界事件的關係

非使用道具可先作為世界中實際存在的「目標物」，而不是由 NPC 需求憑空生成。

```text
迷宮／城市庫存生成實體物件
        ↓
有人得知、想取得，或玩家從酒館打聽到情報
        ↓
購買／運送／尋找／調查／保護委託（也可能不產生委託）
        ↓
物件交付、到期、被購買或流入其他 NPC
        ↓
市場、關係、城市狀態與後續事件改變
```

例子：

- 地城生成一只玉壺 → 可能有人發布取得委託；若無人發布，仍可透過酒館情報得知並自行探索。
- 城市庫存中的陶土被選為貨物 → 可形成購買或運送委託，且委託綁定這一個實體物件。
- 家族搬遷需要祖傳屏風 → 可形成運送委託；它的重量會影響由誰實際攜帶。
- 學者得知一批宣紙與舊帳本存在 → 可形成購買、護送或調查委託。

## 城市庫存、店面與委託生命週期

- 迷宮刷新時，未被玩家或其他冒險者處理的非卷軸道具會轉入其對應城市的**永久庫存**；卷軸不使用這條規則。
- 道具店每月刷新時，先清除上一輪由玩家賣進店內的物品，再從城市永久庫存抽取 1～2 件作為一般販售貨架。
- 庫存物件可被選為購買或送貨委託，但委託必須綁定單一物件 ID，不能用任意同名物品替代。

| 委託狀態 | 庫存類實體道具處理 |
|---|---|
| 未在接受期限前接取 | 道具直接消失。 |
| 送貨接取 | 指定實體鎖入隊伍任務物資空間；抵達目的設施時交付回收，任務改為完成。 |
| 購買／探索取得指定物 | 指定實體鎖入隊伍任務物資空間；回原接取公會結案時交付回收。 |
| 已接取但到達實際結束期限 | 任務轉為到期；仍在任務物資空間的道具解除鎖定，玩家隊逐件競拍、NPC 隊逐件 RNG 分給正式參與者，不回永久庫存。 |

任務物資空間只是鎖定區，不是一般隊伍背包：其中物件無法使用、裝備、出售、拆分或任意轉移。隊伍本身不擁有一般物品；正常財產始終屬於個別角色。
