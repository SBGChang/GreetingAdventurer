# 目前實作狀態

本文件是唯一的實作狀態與未完成項目來源。先核對程式與驗證，再更新此頁；完成的待辦直接移除。歷史留在 Git，不在工作樹保留舊交接或審查副本。

## 正式可用範圍

- 開局／繼續旅程、16:9 橫向場景舞台、固定視角 3D 城鎮模型互動與右側設施頁簽、日期／所在地、繁中／英文、操作回饋、旅程紀錄與死亡結束畫面。Electron 與瀏覽器共用介面，桌面支援 800px 以上視窗，舞台等比例縮放並留黑邊；設施及人物視窗內部捲動。模型建築的滑鼠選取與頁簽的滑鼠／鍵盤選取會同步顯示建築抬升、投影與柔和呼吸光暈及名稱，兩邊皆可直接進入設施。探索按實際房間形狀、相鄰門與樓梯操作，戰鬥呈現共用地面站位、下方放大的隊伍盤與右側全高 CTB 欄。
- 雲華主循環：購買武器與防具／出售背包物品 → 裝備與配招 → 接鎮壓／討伐委託 → 探索地圖與樓梯 → 回合戰鬥 → 出口競價或直售戰利品 → 回原公會領錢與熟練度 → 休息／訓練再出發。
- 城市旅行使用城門口的 3D 大地圖；家園、訓練與酒館招募保留既有正式入口；未開放的設施不顯示可操作按鈕。
- 傷害技能與反擊的倍率已轉成 combat-effect／combat-damage-rule，武器副屬加入傷害，防具按比例減傷；生命／魔力上限包含角色主屬。裝備係數只縮放一次。
- 委託結案、貨幣分配與成長在交易內完成，重複領獎拒絕且不變更存檔。正式開局與刷新會生成鎮壓、討伐、採買、送貨及救援，接取及結束期限都有排程。採買商品在接取後才可購買，送貨接取時領取實體貨物；兩者以公會交貨按鈕完成，報酬仍須回原公會領取。救援必須打敗守衛、救出居民並離圖；暫時同行者不參與戰鬥或獎勵分配。
- 實際內容包以 `content/manifest.json` 為準。目前載入 core、雲華與 world-cities；後者提供其他十二城的城市、路線、文化名稱與住宿。各國完整商品、委託與冒險內容仍未開放。
- 玩家命令由 GameSession 與交易執行器處理，ID 與 RNG 可重播。世界結算使用核心排程排序、完成同日工作，且不倒退日期。
- 新遊戲建立地圖與商店週期工作。地圖刷新間隔與偏移來自 map-template v2；鎖定／有人探索時保留固定日曆及必要的次日重試。
- 戰鬥阻塞原因回傳 UI；未接線 port 產生明確 typed rejection，不把例外偽裝成成功。
- 每次接受玩家操作後自動儲存，另有手動儲存、匯出／匯入 JSON 存檔。重開恢復全部狀態，包含排程、RNG 游標、迷宮、裝備與戰鬥。

行囊的隊形配置使用正式命令儲存 3×3 站位，可交換隊員格位，重開及開戰沿用配置；戰鬥中由引擎拒絕更改。委託狀態彙整各城已接委託，接取與領獎仍在公會；道具分頁顯示背包，使用道具與學習書籍尚未開放。

## 城鎮 3D 場景

同一城市內切換設施、行囊及世界地圖會保留已載入的城鎮模型與鏡頭位置，隱藏期間停止繪製；購物、裝備、隊形與自動存檔只更新介面資料。換城或進入冒險地時才釋放舊城場景，重新進城時載入對應模型。

玩家介面使用[類別圖集與城內標籤](../app/assets/ui/README.md)，右側設施頁簽無底板，粗體描邊文字與 Hover／鍵盤選取同步模型光暈。底部保留行囊選單，內含裝備、隊形配置、委託狀態與道具。設施使用[四文化接待美術](../app/assets/facilities/README.md)：左側招待員立繪、四文化九宮格對話框及玩家選項；對話框採固定角飾與純色中央，正文和補充資訊分隔，長文可拖曳／滾輪／鍵盤捲動，右側連續清單與詳情；詳情使用四文化共四十種獨立職務美術，按目錄取樣並在個別文字安全區內捲動，不再淡化外框作為底板；無搜尋欄及分頁，清單按住上下拖曳捲動且不顯示捲軸，拖曳不觸發項目選取，保留滾輪及鍵盤操作。安居牙行整頁外框已改為九宮格試作：固定四角與框寬、四周雕花邊條分段重複、中央純色填滿；其餘外框及詳情素材仍使用原圖集。標題以共用匾額置中跨在視窗上緣、一半突出，返回圖示在右上框角。分類、清單與確認採細金屬邊共用按鈕美術，不再縮放文化面板作為按鈕；分類及確認操作放在招待員區，選取不提交命令。旅館確認住宿，城門使用 3D 地圖並由招待員區確認旅行方式與出發。四文化各十種設施共有 40 位獨立招待員、160 個表情格、40 種面板及四文化返回圖示；名稱與台詞由正式呈現目錄提供，設施名稱亦編譯到語言包。一般對應進入／檢視，開心對應正式成功，生氣對應正式拒絕，沮喪對應條件不足／空清單／招募失敗／例外。角色僅是呈現人物，不加入世界人口與隊伍；其餘三國仍只開放住宿與城門，完整美術不代表專屬玩法已完成。`/facility-art.html` 使用隔離假資料檢查全 40 組美術與四表情，不讀寫存檔。設施開啟時收起城名牌、旅程紀錄與進度管理，關閉後恢復；純圖示返回鍵保留本地化提示及無障礙名稱。介面不顯示捲動條，長詳情與對話可獨立用滾輪、鍵盤捲動。城名牌依所在地選取四國美術，包含城市、世界日；語言選項位於進度管理。商品圖示仍為類別美術。

正式遊戲使用 `app/TownModel.tsx` 載入 Blender GLB，模型點擊與右側頁簽均連接既有設施操作，名稱及可操作性來自目前城市的 GameView。雲京十處功能建築分散於 36 棟不可互動住宅／倉房之間；重簷、特色屋瓦、煙囪、棚架與牌樓建立視覺層級。射線只接受最前方可見模型，街坊不會穿透點到後面的設施。

雲京包含四面城牆、角樓、水道、市集與三座固定橋梁：石拱橋落在北岸與西南岸，西側木橋連接外坊，南支流木橋連接東西岸；橋梁具備連續橋身、兩岸支承及引道，並排除裝飾自動刪除。正式城內使用固定角度的街區近景，預設以中央街坊為主、大部分城牆在畫面外，按住滑鼠左鍵或右鍵只做上下左右平移，沒有旋轉與縮放。模型 Hover 稍微追焦，頁簽／鍵盤選取會帶向對應設施；拖曳優先並抑制誤觸進入設施。大地圖中的城池預覽仍維持全城視野。即時陰影、模型浮起及呼吸光暈已接入正式介面。減少動態效果偏好停用浮起、光暈脈動與平移補間。載入或 WebGL 失敗會顯示錯誤與重試，仍可用設施頁簽操作；離開城鎮時釋放動畫與 GPU 資源。

城鎮作者工具在配置住宅與樹木時檢查獨立建築、文化地標及景物的幾何交叉；階台建築按完整占地決定高度並補基座。大地圖減面保留地基、階台、路面與城垣的結構輪廓，城市完整占地周圍預留平地，外部道路、水道與樹木避開城池。城門朝向與牆體缺口一致，木柵與山坡留出通道；港城西岸保留建築乾地，赭階橋補齊下橋階梯，冰鑿採石台落在岩床與台階上。輸出後以 Blender 再檢查十六城及大地圖的城市／環境交叉、雲京橋梁的乾地落點與橋面、三十二處城門通道、港城地基與赭階橋引道，驗證結果綁定受檢模型雜湊，避免修改模型後沿用舊結果。

[場景美術](../app/assets/README.md) 記載可編輯模型與重建入口；[十六城街區契約](../app/assets/geography/README.md) 記載各城布局。十六城住宅均使用新版街坊建模：雲京有書香院落、河邊店屋及東西岸住家，赤帆有商旅、織戶、陶戶與南側家庭院落；其他十四城各有依產業與地形配置的四個街區、公共廣場和四種市場攤位。住宅使用附翼長屋、開放院落、工坊工作院、並列店屋、塔式住家、騎樓、錯層雙屋、架高穀倉與菜圃小屋等實際結構，各屋翼具有自己的屋頂、門窗及支承；功能建築維持較大尺度。巷道隨住宅朝向配置，私人院地、公共道路及草地／雪地／沙地分開使用固定比例 UV 材質。市場具有不同寬深、高度與棚架曲面，依當地產業陳列貨品。木石作、屋瓦、板岩與薩菲爾藍釉、織布使用封裝色彩圖與法線；屋側窗、上層樓廊、門前收納、菜圃及工作棚補充近景細節。

雲京保留三岸水道與三座固定橋梁，赤帆保留驛道、市集及中央水池骨架；其他十四城的街網連接實際住宅、設施與攤位入口，青岑跨階台使用有支承的階梯。世界城市縮景由同一份城內模型重建。標題使用雲京渲染圖，設施視窗使用所在城市的渲染圖，舊 2D 城鎮圖及輪廓遮罩已移除。上述為靜態美術；尚無人物、環境及轉乘船隻動畫，也不新增商品或 NPC 行為。

城門口進入 [3D 四國輿圖](../app/assets/geography/README.md)，預設聚焦玩家周圍城市，可巡覽、旋轉、縮放並切換全圖總覽，選取城市並開啟模型預覽。大地圖是一片連續大陸，雲華與薩菲爾之間形成四周被陸地包圍的雲星大湖，使用適量網格呈現雪峰、丘陵、分支山脊、台地與峽谷的幾何高低差；道路依網格表面取樣貼地，搭配 UV 地表／岩層色彩貼圖、烘焙法線、材質粗糙度、各向異性取樣及陰影；城市縮景保留整城城牆、街坊與地標的減面版本，主堡比小城大。包含河流、森林、雪地、沙地與曲線道路；城市位置和道路折點是美術作者資料，東西南北文化方位沿用正式設計。所有城際連線均對應正式路線：國內道路加上青岑—燼鐵、白崖—霜灣、風穗—鹽鏡、澄浦—赤帆跨國陸路，以及雲京—星井渡湖線。地圖提供「可直達」入口；非相鄰城市需轉行。湖面虛線只畫水上航段，沿岸接回道路；旅行使用正式 3／6／9 日模式。預覽不改變存檔，旅行選項仍由正式 GameView 決定。

## 地牢 3D 場景

正式雲華九張冒險地圖均提供 [Blender 模型與材質](../app/assets/dungeons/README.md)，共十八層、一百七十一個房間，按正式 Content Pack 的占地、門與跨層通道建模。舊漕渠為水工倉庫、司曆殘院為觀星遺庭、天衡印塔為六層藏卷與封印建築；霧篁藥谷、懸泉石窟、潮生蘆洲、鹽井封窖、朱砂斷嶺及古窯火道分別使用竹林、泉岩、蘆葦水岸、結晶鹽窖、赤岩採場及窯體陳設。自然地表、室內石板與岩壁分別使用 UV 色彩圖及封裝法線。

各層以連續實地為主，景物收在實際房間邊界，中央保留人物與怪物活動區；門口不放陳設，樓梯使用小型角落井與繞行平台。匯出後以實際 GLB 驗證角色足跡、內部通路、門口、中央留空及階梯踏面，碰撞遮罩和檢查結果綁定模型雜湊。部分正式模板原有共用拓樸，場景建模保留其玩法連線，未宣稱九張圖有九種全新拓樸。

正式探索與測試入口共用 `DungeonAdventure`／`WalkScene`／`walk-controller`。正式入口注入 GameView 的探索身分、地圖版本、房間占地、進入格、門狀態、隊伍與目前房間的真實內容。WASD／方向鍵自由行走；跨房先提交正式移動命令，收到新房間投影才移入並切換亮房。關門會阻擋人物；門與樓梯在場景實際位置顯示光環與互動提示，走近後可點選或按 E 開門／上樓／下樓，遠處提示不接受操作，長按 E 不重複送出。互動位置依正式連線格與模型樓梯平台換算，距離參數在 `walk-presentation.json`。房間內容及出口按鈕沿用既有正式命令。小地圖共用已載入的 3D 場景做垂直空拍，北方固定朝上，依已探明房間調整取景；綠色我方箭頭同步人物的房內實際位置與朝向。未知房間的模型不參與小地圖繪製，沒有黑格、外框、名稱或出口符號，已探明房間的門以圖示區分未開／已開，上樓與下樓以金色／藍色階梯箭頭標在實際平台，同處多個方向並排，過近的標記錯開並以細線指回實際位置。門後與另一層的未知房間不因標記而揭露；離開房間後保留已知地形，其他房間內容維持隱藏。房內走動不推進世界日期，跨房與開門使用正式規則結算分鐘。

同層開門、跨房與介面狀態更新保留模型及人物位置；戰鬥期間保留原場景可見、凍結人物和鏡頭，隱藏探索 UI，在上方疊加壓暗與毛玻璃；行囊與分配期間才隱藏場景。戰後移除疊層，沿用同一個 Canvas、模型、材質及房內位置。換層、探索身分／版本改變或離場才更換或卸載模型。重新開遊戲並選擇繼續時，依存檔中的房間與進入格恢復，房內細部座標不寫入存檔。只有目前房間亮起及顯示陳設，其他房間保持昏暗結構。

`/dungeon-3d.html` 提供九張地圖、十八層的美術總覽；`/dungeon-walk.html` 提供獨立測試入口，以 `app/testing/adventure-fixture.ts` 注入假探索與門狀態，可切換地圖／樓層、開門、走樓梯與離場，亦可拒絕下一次移動。戰鬥透過 `combat-sandbox.ts` 建立獨立固定種子的測試世界與已配裝隊伍，執行正式技能、敵方回合及勝負；勝利才清除測試遭遇，戰敗重置測試入口。測試頁完全不读写存檔，正式入口的傳遞依賴禁止引用 fixture。步速、動畫與鏡頭参数在 `walk-presentation.json`；碰撞遮罩取自實際模型並使用小步進。

目前房間的未清除怪群／Boss 以代表模型顯示，可點選模型或內容卡交戰；模型身分由正式怪物編組提供，非目前房間不顯示怪物。場景預留怪物與人物間距，戰鬥後依正式內容是否清除來移除模型。

`CombatScreen`／`CombatArena` 已取代舊 SVG 角色卡片：雙方依正式 3×3 隊形與自動補位站立，提供 HP／MP、CTB 行動順序、技能／目標選取、休息、生命變化數字、受擊與倒地，以及勝敗確認後返回探索。Session 在每個敵方動作提交後供門面讀取快照，`combatFrames` 串起玩家及敵方回合；介面不計算傷害、不推進 CTB 或世界日。正式動作提交後即存檔，演出期間禁止重送，勝負確認前保留戰鬥畫面；讀檔恢復已提交狀態，不重播動畫。技能目標是否合法仍由正式引擎驗證。

`CombatScreen` 是透明的前景疊層，背景由發生戰鬥的場景持有；雙方站在同一大塊連續地面，採五張獨立繪製的濕石、泥草、城市鋪石、岩地與沙地 UV 圖，加上各地色調；九張地圖、十六座城市及全部道路均有明確美術綁定，2D 與 3D 共用。人物與 UI 保持清晰。正式入口以交戰地點資料選圖，測試入口可用 map／city／route 指定對應背景與地塊；載入完成才開放操作。地牢的正式交戰與返回已接線；主城／世界地圖具備凍結與保留模型的呈現支援，`/combat-2d.html?formation=full&scene=city`／`scene=world` 注入測試戰鬥供驗收，不表示已新增城內或世界地圖遭遇玩法。背景模型只在真正離場、更換模型／探索身分時釋放。

共用戰鬥 HUD 使用獨立繪製的金銅雲紋頭框與紅色 HP、藍色 MP、金色 CTB 條。右側單一直列容納全部存活單位（最多十八個），CTB 先顯示已提交事件的行動後延遲，再以 0.45 秒線性補間呈現排程倒扣，直到下一位歸零才亮起行動頭框；頭像依正式順序移位，等待指令時暫停。同批已就緒單位不額外倒扣，失能者沿用引擎端點，勝負確定不再推進。CTB 條長在 100 封頂，完整數值保留於懸停資訊與輔助讀取；死亡者移出，戰鬥結束收起。下方並排放大的我方與敵方 3×3 隊伍盤，右側另留完整高度給放大的 CTB 列，空位不顯示單位資訊，實際格位提供頭像、HP／MP 美術條及目標選取；角色身上的名牌與資源條已移除；戰鬥期間收起探索用行囊、地點牌、訊息與旅程／存檔選單，避免遮擋隊伍盤。滿格與空格均沿用實際隊形，補位時優先顯示該格存活者。我方每次輪到行動時自動展開壓暗戰場的美術選單，三列武器徽框各對應三個實際配招欄；未裝備／未配置欄位保持空白停用，使用中組合有箭頭與亮框。點其他組的技能會隨正式 useCombatSkill 帶入 weaponSetId，切換與延遲由引擎提交，下一回合標示更新。選技能後收起選單，只高亮正式目標解析與射程檢查允許的存活目標，資源不足的技能停用。Esc 取消選取回到選單或關閉選單；關閉後可點目前角色格重開。休息維持正式回復及延遲；防禦入口篩選已配置且可用的 guard 招式，沒有時停用。使用道具保留需求中的美術位置並標示不可用：useCombatItem 尚缺效果套用、行動延遲與庫存提交的完整交易，未註冊正式命令。Hover 隊伍盤或行動列會高亮對應角色。已支援 2D 單位從原始待機序列取頭像，尚無對應肖像的 3D 單位明確使用名稱首字。已排定的同值 0 CTB 沿用引擎 readyQueue，尚未排定者不預測未來 RNG。狀態色目前僅標明失能，施法／架勢／硬直的完整狀態提示及技能延遲預覽尚未接線。

[戰鬥美術契約](../app/assets/combat/README.md) 的程序模型仍供探索中的隊伍／怪物代表，以及未登記武器混搭的戰鬥備援使用；正式相容遭遇使用 2D 序列。探索模型尚未改成逐角色裝備造型，場景怪物也沒有巡邏／追擊 AI。地塊按地貌共用五種原畫及色調；目前不是即時戰鬥，其餘三國尚無正式冒險地圖資料。

[序列美術契約](../app/assets/combat/sprites/README.md) 已提供四國各男女 × 偏文／偏武，共十六種外觀，每種涵蓋十六個動作族：空手、單手盾、單手武器、長柄、雙手重刃、投擲、弓、弩、單手法杖、雙手法杖、管樂、弦樂、打擊樂、刀盾、大盾與雙持，共 256 個人物組合；另有全部已定義的 65 種怪物（60 種非人與正式雲華 5 種人形敵人）。包含 319 張新增原始圖集及既有角色／潮殼蟹分段圖集。人物提供待機、攻擊、受擊、格擋、閃避及倒地六段，各六格；怪物至少提供待機、攻擊、受擊及倒地，兩個人形首領的攻擊為十二格。按武器種類共用代表兵器造型，不表示每件斧、扇、琴等裝備已有獨立圖像；法杖加盾等異種混搭仍缺相容圖集，會保留 3D 備援。其餘三國的 45 種怪物已有美術與身分綁定，並不表示其正式冒險內容已開放。

正式與測試入口共用 `CombatScreen`，依參戰者身分、真實性別、已提交武器組及怪物 ID 選圖。預設女性及世界招募角色已有對應序列；行囊人物頁可選擇與角色性別相符的八種文化／氣質外觀，保存於本機獨立美術偏好，重開沿用，不改變能力、性別或 RNG。新遊戲與清除存檔時清空外觀偏好；遊戲 JSON 匯出不包含這份偏好。武器切換即使用新武器組動作，雙手持同一件物品不誤認成雙持，空手使用獨立序列。圖集與逐格資料依參戰者及其武器組載入，HUD、外觀選擇與戰場共用快取；不在開局下載全部原圖。已登記素材載入錯誤會明確報錯，不靜默換成其他角色。

圖集由內建 image_gen 製作，保留未改寫像素的原 PNG 與完整來源提示詞；透明度有誤時重繪，載入時做洋紅色鍵合成。逐格區域、輪廓、腳底與時間由資料提供，取樣綁定原圖雜湊及分析版本；分離刀光／音波按原格歸屬，避免混入鄰格。角色長寬維持原版樣本的一半，單一連續地面可容納雙方各 3×3，共十八個可分別選取單位，資訊在下方隊伍盤。30 FPS 是播放時間取樣，六格原畫仍是六格，不以骨架變形或插值冒充新增畫格。

`/combat-sprites.html` 可選全部人物／武器／怪物，檢查正常速度、慢速、逐格、六格並列及明暗底色；`?catalog=characters&motion=blade` 與 `?catalog=monsters&page=0` 提供圖鑑。`/combat-2d.html?appearance=safir-female-scholarly` 可用指定外觀進入正式引擎的隔離水道測試；預設仍是原雲華男性偏武樣本。`/dungeon-walk.html` 的測試遭遇沿用固定水道戰鬥，其他測試地圖不冒充各自怪物內容。測試不讀寫玩家存檔。正式遊戲已驗證購物配裝、選擇外觀、存檔重開、探索交戰、勝利及返回保留的場景。

2D 動作消費已提交的 `CombatFrame.actions`：休息不出招，攻擊命中格與 HP 更新對齊，重刃可指定斬落格，遠程原地出招，反擊架勢可播放防禦，實際死亡才倒地。格擋成功與閃避尚無獨立引擎結果事件，不能把已有預覽素材視為判定功能已完成；逐招獨立特效與更細過渡格仍未完成。

## 開局與平衡

`content-source/player-scenario.ts` 是開局設定，預設從雲京、25 歲、5,000 旅費開始；單手武器／中甲 Lv.5、投擲 Lv.3。仍需自行購買裝備並配招。Tier I 怪群為三隻；初期可從舊漕渠與沉倉開始，打一場後找出口返城。這是目前作者層的可調首版平衡，並非宣稱四國 GDD 全部完成。

### 世界內容與委託來源

開局立即生成九張雲華地牢的遭遇與商店商品，並用正式生成 Handler 建立公會委託。怪群以 35% 機率形成鎮壓，Boss 與被擄者必定形成當地委託。採買／送貨只反應於材料、消耗品及一般貨物，不保留裝備與書籍；每件實體貨物最多對應一張有效委託，送貨目的地必須有公會且距離不超過規則指定的城際路段數。

九張地牢共有 33 組怪群、2 組 Boss；舊漕渠與沉倉、霧篁藥谷、鹽井封窖及古窯火道各有一位被擄者與一組實際守衛。房間內容只有抵達後才能互動；介面顯示尚餘遭遇數及救援守衛數。已接取地圖委託會阻止一般刷新替換目標，未接取且來源已被刷新移除的委託撤下。

開局不預先推進世界日期。地圖與商店週期刷新已運作；NPC 自主行動與世界局勢仍屬下列待完成範圍，多跑日期不會補出未實作的事件。

## 存檔行為

單一本機槽位及上一份備份，儲存在瀏覽器 Storage；Electron 的網站儲存由自己的 userData 管理。桌面、開發網站與不同網站 origin 不共用槽位。進度管理可清除本機主槽位與備份，確認後回到建立旅程畫面；清除網站資料也會移除存檔。

讀取前檢查 checksum、存檔版本、Content Manifest Identity、由型別產生的 JSON Schema、核心時鐘／序號、玩家隊伍與排程。損壞或不相容的存檔拒絕載入，畫面提供備份還原或重新開局；不靜默重置。寫入失敗顯示錯誤並保留既有主存檔，已成功的遊戲動作不回滾。checksum 用來偵測損壞，不是防修改簽章。

支援本次修正前的十六城版本（完整來源內容身分與 schema 雜湊列於 `src/app/save/content-upgrade.ts`）升級。升級不推進日期、不重置角色、金錢、裝備、門、地圖版本或既有委託，只補缺少的內容種類與可用商品的委託反應；新存檔再次載入不會重複補內容。其他未知內容版本仍拒絕載入。未提供跨裝置同步或 Steam Cloud。

- `npm run verify:geography`：十六座模型各自不同、十種設施根節點、街坊、世界地標與全部正式城際連線；另檢查地表是一片連通陸地、只有外海岸與內陸湖岸兩個閉合邊界；幾何交叉檢查結果必須無錯誤，且 SHA-256 與目前十六城及大地圖的 `.blend`／`.glb` 完全一致。
- `npm run verify:world-travel`：正式內容逐城旅行、住宿、日曆推進、抵達存檔重載與回到雲京。
- `npm run verify:atlas`：隔離存檔實際查看十六城、確認預覽不改動狀態，旅行至全部十六城，驗證跨國陸路、渡湖線、抵達存檔及雲華地標射線。
- `npm run report:content`：目前實際載入資料與缺少的 resolver binding；不是完成率。
- `npm run verify:gap`：文字掃描供查找線索；會命中否定句和設計說明，不能直接當作未完成清單。

## 文件與資料維護

- `docs/00_core/architecture/` 是目標契約；是否已接線只看本頁與正式流程測試。
- `content-source/` 是 runtime 作者層，修改後執行 `npm run content:packs`。
- 四國閱讀版由 `npm run content:all` 產生，不手改 HTML。
- map-template v1 沒有刷新週期欄位。作者資料須依該國設計明確升為 v2；不在 runtime 猜測週期。未列入明確升級契約的舊版存檔在內容身分不符時拒絕載入。
- 修改存檔結構後執行 `npm run schema:save` 並檢查存檔相容策略；不可只改 JSON 產物。
