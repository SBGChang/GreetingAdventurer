# 遊戲資料內容的審查結果

> 審查日期：2026-08-16  
> 審查基準：`536a426`，以及當時工作樹中尚未提交的四國內容調整  
> 範圍：四國地圖資料、地圖配置差異、HTML 實際顯示產物  
> 不包含：引擎流程與驗證器實作；這些列於《程序與結構的審核結果》

## 結論

目前四國內容已擴充到預定的城市與冒險地數量，但還不能視為完成資料。雲華有 7 筆正式地圖規則違反；維爾敦、奧雷連與薩菲爾的 27 張命名地圖實際只使用 3 種完全相同的拓樸；四份 HTML 的樓梯顯示也仍是錯誤產物。

## P1：雲華九張地圖目前有 7 筆規則錯誤

以共用 `validateMapLayouts()` 驗證 `docs/03_content/yunhua/yunhua_content.data.mjs`，結果如下。

### 舊漕渠與沉倉

1. `地上 1F｜沉倉入口` 的 `東側沉倉`、`東側下行梯` 沒有連到本層其餘部分。

### 天衡印塔

2. `塔 1F｜入塔廳` 的紅門 `入塔前室 → 下行封門梯` 兩側都沒有寶箱、事件或大型敵人偏好點。
3. 塔 1F 的下行樓梯位於 `[4,2]`，塔 2F 的上行樓梯位於 `[3,3]`，座標不一致。
4. 塔 4F 沒有上行樓梯，無法回到塔 3F。
5. 塔 3F 的下行樓梯 `[3,3]` 找不到塔 4F 對應的上行樓梯。
6. 塔 4F 的下行樓梯 `[2,4]` 與地下一樓的上行樓梯 `[4,2]` 座標不一致。
7. 最上層塔 1F 放置了不應存在的上行樓梯。

### 修正原則

- 先確定天衡印塔的正式樓層順序，再逐對校正樓梯；不能只調整符號，座標也必須相同。
- 塔 4F 若同時連接塔 3F 與地下 1F，需要各自獨立的 1×1 上、下樓梯房間。
- 舊漕渠東側區域若是刻意「看得到但走不到」，仍必須透過其他樓層形成合法路徑；若不是，就補上本層連線。
- 紅門後應安排寶箱、事件或大型敵人偏好房間；樓梯房本身不能兼任內容偏好房間。

## P1：27 張命名地圖只有 3 種實際拓樸

維爾敦、奧雷連與薩菲爾各有 9 張地圖，但目前都只是呼叫 `standard_layouts.mjs` 的三個固定建構器：

- `wildernessLayout`
- `twoFloorLayout`
- `nationalDungeonLayout`

名稱、城市、樓層說明不同，但房間座標、形狀、通道、紅門、陷阱、樓梯與內容偏好點相同。

### 維爾敦

- 同一二層拓樸：沉潮船塚、黑岩獸穴、古炭礦坑、鳴骨燈塔。
- 同一野外拓樸：斷帆冰窟、白杉獵原、風碑裂谷、灰潮礁群。
- 國家迷宮拓樸：長夜誓塚。

### 奧雷連

- 同一二層拓樸：舊鐘渠堡、斷旗烽堡、舊橋稅堡、王獵行宮。
- 同一野外拓樸：晨輝演武苑、荊野古道、銀麥河廊、燭岩採場。
- 國家迷宮拓樸：七塔誓院。

### 薩菲爾

- 同一二層拓樸：埋砂商站、風蝕駝堡、沉井水宮、日盤貨棧。
- 同一野外拓樸：星井下渠、棕影鹽澤、棗泉密林、赤帆礁灣。
- 國家迷宮拓樸：月環星臺。

### 影響

- 地圖名稱與敘述雖有文化差異，實際探索路線與成本完全相同。
- 紅門、寶箱、事件、大型敵人與素材偏好點的空間設計無法表達各地特色。
- 玩家進入不同國家後，只會看到相同地圖換名字，削弱探索內容的價值。

### 建議修正

保留共用模型與驗證器，但每張地圖應提供獨立拓樸資料。共用函式可以協助建立房間與連線，不能把整張固定版型當成九張正式地圖。

第一輪至少應做到：

1. 同一國家的九張地圖沒有完全相同的房間與連線簽章。
2. 國家之間的國家迷宮不得共用完全相同的六層路徑。
3. 紅門後方的偏好內容、素材採集點與跨層繞路應呼應地圖名稱與環境。
4. 地圖筆記必須描述實際存在的路徑特徵，不能只有敘事換皮。

## P1：目前四份 HTML 樓梯顯示皆不正確

直接檢查現有 HTML 產物中的樓梯符號：

| 文化 | 地圖數 | 向上樓梯 | 向下樓梯 |
|---|---:|---:|---:|
| 雲華 | 9 | 0 | 20 |
| 維爾敦 | 9 | 0 | 18 |
| 奧雷連 | 9 | 0 | 18 |
| 薩菲爾 | 9 | 0 | 18 |

這不是合理的樓層資料結果，而是 HTML 產物仍把上樓梯畫成下樓梯。

### 修正順序

1. 先修正雲華的獨立 Renderer，或將它移除並改用共用 Renderer。
2. 修正雲華前述 7 筆地圖資料錯誤。
3. 確認四國共用驗證全部通過。
4. 最後重新生成四份 HTML。
5. 在建置檢查中加入基本不變量：只要存在兩層以上的相連地圖，產物不得只有下樓梯而沒有上樓梯。

- 上述「通過」只代表結構合法，不代表地圖內容已具備足夠差異；固定版型重複仍須處理。

## 完成判準

本輪內容問題可在下列條件全部成立後關閉：

- 雲華共用地圖驗證結果為零錯誤。
- 四國 Builder 都使用同一地圖模型、驗證器與 Renderer。
- 每張正式地圖都有自己的房間／連線配置，沒有單純改名的完整拓樸複製。
- 四份 HTML 重新生成，且上下樓梯數量與資料一致。
- 生成後的 HTML 能通過自動化內容檢查，而非只靠人工目視。
