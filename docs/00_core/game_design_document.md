# 遊戲基礎設計文件
> 靈感來源：俠客遊（Lunatic Dawn）系列，重新設計

---

## 核心哲學

**事件先於一切。**

委託、地圖狀態、NPC關係，全部都不是獨立設計的內容，而是「世界事件」的下游產物。事件本身則是NPC決策互相碰撞的自然結果，不是靠事件生成器手動編排。

玩家沒有固定目標，扮演一名冒險者，靠接委託維生、提升自己，一直到角色老死為止。角色死亡後可繼承隊友、子女或家人繼續遊戲。

---

## 一、世界模擬系統

### 時間推進
- 採用「玩家行動觸發＋批次結算」模式
- 玩家做了耗時動作（旅行、睡覺、進地城）才觸發世界往前結算
- 不是24小時空轉的即時模擬引擎

### NPC模型
每個NPC只需要四個維度：
- 身份標籤（商人、衛兵、冒險者、平民等）
- 當前需求（缺錢、缺安全、想要復仇等）
- 所在位置與可及範圍
- 簡易關係表（只記「跟誰有未了結的事」）

### 事件生成邏輯
- **事件 = 決策的交集**，不是獨立生成的內容
- 每個NPC每天從行為池選一個動作，兩個動作的位置和時間重疊時，事件自然浮現
- 大部分NPC日常行為直接靜默結算，只有碰撞才升級成事件
- 分層精細度：背景層（純統計）、在地層（簡單決策）、互動層（完整模擬）

### 事件外溢
事件發生後分流到下游系統：
- 影響地圖狀態嗎？
- 產生委託嗎？（不是每個事件都會發委託，取決於受害者能力和管道）
- 更新NPC關係表嗎？

## 二、事件系統

### 目前確定的事件類型
- **掃蕩**：小魔物佔據某個地城（純隨機觸發）
- **鎮壓**：大型魔物佔據某個地城（純隨機觸發）
- 其他委託需求類事件（護衛、運送、調查、救援等）由城市NPC的需求自然產生

### 事件與地圖的關係
- 事件可在地圖上增加目標、佔據狀態或特殊報酬，但不是城市、可探險地與一般怪物內容的必要來源。
- 地城的特殊「當下狀態」可被玩家消耗（清完、拿完就沒了）；新特殊狀態由新事件觸發，不是定時刷新。
- 玩家透過打聽消息得知地圖發生了什麼

## 三、委託系統

### 核心原則
- 委託不是內容入口，只是事件的一種**可選包裝**
- 委託一定會發生，但玩家不一定會看到（不知道委託發在哪）
- 玩家可以完全不靠委託板，自己撞見同一個事件
- 打死龍但沒接鎮壓委託，一樣有歡呼，但沒有正式獎勵

### 委託類型
- 購買/取得某樣東西
- 運送某樣東西
- 護衛誰去哪裡
- 討伐/鎮壓附近威脅（掃蕩/鎮壓）
- 調查某件事
- 救援誰

### 委託來源
- 只有非冒險者角色可以發委託
- 冒險者（含玩家）負責接委託

## 四、地城系統

### 地圖結構
- 每個可探險地先定義地圖模板，而不是先定義怪物或事件。
- **野外**固定為單層 8×8 格；可部署、遭遇與探索都在同一層完成。
- **內部地圖**的每層為 4×4 或 5×5 格。洞穴通常由地上一層向下延伸，最多至地下三層；塔可由地上最多三層與地下最多三層組合。除野外外，實際要使用幾層可依地點自由決定。
- **國家迷宮**另用較大的模板：野外型固定 10×10；非野外型固定 6×6。地牢型固定為地上 1 層、地下 5 層；建築型固定為地上 4 層、地下 2 層。
- 格子與格子之間必須有通道或門才能通行；兩者皆無即為不可通過的空間。門與通道的位置屬於固定模板資料。
- 連接兩層的樓梯必須使用相同的列、行座標：上層的 `↓` 與下層的 `↑` 永遠落在同一格。小地圖因此能正確顯示垂直關係，也可設計同層看得到卻必須經下層繞行才能到達的區域。
- 相鄰的小格之間若沒有牆線，代表它們是同一個房間的合併格，不是通道縫隙；房間可以是 L、T、凹形等任意形狀，不必限制為 1×1。
- 每個合併房間才是一個可選擇的移動節點。玩家只在房間與房間之間移動，房內沒有移動行為；移動時的疲勞成本才依該房間覆蓋的實際小格數計算。
- 樓梯、陷阱、寶箱／事件／大型敵人偏好等皆附屬於房間；圖上的圖示座標只用於辨識與小地圖對齊，不另形成一個可移動格。
- **入口、出口、樓梯與固定陷阱**是互斥的單格功能房間，必須各自獨立為 1×1；其中不可生成怪物、寶箱或事件，也不可與另一種功能共用房間。
- 每個探索地圖合計配置 **1～3 個出口**；出口可位於不同樓層，但皆計入同一探索地圖的出口數。
- 房間、牆壁、通道、門與陷阱位置固定；陷阱類型固定，僅啟用、解除或觸發後的狀態會改變。
- 模板可標記偏好格，例如寶箱／儲物格、大型敵人格、綁架／囚禁格、伏擊格等；寶物、大型敵人與事件依標記放置。大型敵人格必須位於長、寬皆至少 2 格的大房間；事件偏好格至少位於由 2 格以上組成的中型房間。一般怪物沒有偏好格，可生成於任一可通行且允許生成的普通格。
- 玩家探索過會記錄小地圖，**跨場保留**
- 陷阱屬於空間知識的一部分，走過就知道

### 內容機制
- 每個可探險地有固定的「所在地文化」產物與非人類怪物池；怪物池只依文化區分，不依城市或個別探索地細分；不需要先有事件才會成為基本探索內容。
- 人類敵人另讀取「目前佔領國」的文化池；地點被他國佔領後，當地物品與非人類怪物不變，只有人類敵人的武器、裝備、技能與外觀改變。
- 所有敵對遭遇以擊殺結束；不設投降、談判或逃離的戰鬥結算分支。
- 物品、怪物與事件皆為動態內容；生成時依地圖模板的偏好格放置。事件只額外改變目標、數量、特殊佔據者或報酬，不取代地點本身的產物與怪物池。

### 一天的結構
- 玩家動一天，世界就動一天
- 地城探索消耗時間，影響疲勞基礎值

## 五、成長系統

### 主屬性（五項）
| 屬性 | 說明 |
|------|------|
| 肌力 | 力量、爆發力、承受衝擊 |
| 智力 | 魔法、學習、預判 |
| 反應 | 速度、感知、即時判斷 |
| 協調 | 精準度、靈活度、力量傳遞效率 |
| 魅力 | 社交影響力（熟練度＋聲望合成） |

主屬性由**熟練度的累積**帶動成長，每種熟練度對應不同的主屬性成長比例。

### 聲望
- 獨立系統，同時作為魅力的輸入之一
- 影響委託機會、NPC態度、能招募的冒險者品質

### 副屬性
由「主屬性×武器/防具配方×熟練度係數×招式熟練度係數」合成：

**物理系**
- 物理傷害
- 命中
- 迴避
- 預判
- 格擋
- 一般減傷
- 格擋減傷

**魔法系**
- 魔法傷害
- 魔法命中
- 魔法減傷

**樂器系**
- 樂器傷害（絕對命中、不吃一般減傷）
- 樂器減傷（頭盔重量＋年紀決定）

### 副屬性公式
```
副屬性 = (主屬性 × 武器/防具權重配方) × 持握係數 × 熟練度係數 × 招式熟練度係數
```

**持握係數：**
- 單手持握 / 雙手持握：× 1.0
- 雙持左手：× 0.5
- 雙持右手：× 0.35
- 雙持總輸出 = 左手結果 + 右手結果

### 副屬性對應主屬性
| 副屬性 | 主屬性組合 |
|--------|-----------|
| 物理傷害 | 肌力＋協調 |
| 魔法傷害 | 智力 |
| 命中 | 反應＋協調＋智力 |
| 迴避 | 反應＋協調＋智力 |
| 預判 | 智力＋反應 |
| 格擋成功率 | 反應＋協調 |
| 格擋吸收 | 肌力 |
| 一般減傷 | 肌力＋防具 |
| 魔法減傷 | 智力＋魔法熟練度＋裝備 |
| 移動速度 | 肌力＋協調 |
| 生命值 | 肌力 |
| 樂器減傷 | 頭盔重量＋年紀 |

### 敵人六屬性卡

- 敵人的戰鬥資料固定顯示六欄：**生命、肌力、智力、反應、協調、魅力**。其中後五項沿用角色主屬性與副屬性公式；生命是敵人直接持有的戰鬥值。
- 魅力對非人類敵人可代表威嚇、號令、群體感應或特殊存在感；沒有相關技能時可為 0。
- 敵人同樣沒有普通攻擊，所有傷害、架勢、施術與移動干擾均以技能執行。
- 一般敵人固定 **1 招**；菁英與 BOSS 依定位配置 **2～4 招**，任何敵人不得超過 **4 招**。

## 六、角色生命週期

### 年紀與屬性
- 1~18歲：所有數值持續上升
- 25歲後：逐年下降
- 例外：樂器減傷隨年紀增加

### 老化與死亡
- 角色最終會老死
- 死亡或退休後可繼承隊友、子女或家人繼續遊戲

## 七、傳承系統

### 資產傳承
- 金錢、道具、房產

### 血脈傳承（子女）
- 子女繼承父母的天生能力值傾向
- 出生時所有數值為0，但15歲成年前熟練度成長很快
- 15歲前只能待在家裡，不能加入隊伍
- 15歲成年後成為正式冒險者
- 可以同時有多個子女，分散培養方向
- 未被選為主角的子女會成為NPC冒險者繼續活動

### 師徒傳承
- 隊伍共同成長：同行的人因彼此行為得到微量熟練度提升
- 指導行為：一對一消耗時間，給予大量熟練度（成年人）
- 小孩教育：在房子裡配置老師，持續教學

## 八、房子系統

### 基本結構
- 一座城市限定一間房
- 買房時決定Slot數量（越大越貴）
- 可以跨代繼承
- 可以在多座城市同時擁有房子

### 初始配置
- 房間（休息、生育）
- 倉庫

### 可擴充功能間
- 教育間
- 鍛造間
- 練藥房
- 會客室
- 陳列室
- 演奏廳

### 小孩教育
- 在房子裡配置老師（自己、隊友、家人、雇用NPC）
- 指定老師教導方向
- 老師在配置期間持續消耗時間教學
- 小孩會自己選擇要找哪個老師上什麼課
- 可以指定重點（提高該方向的選課權重）
- 老師品質影響教學效果
- 除自己外，讓隊友或家人當老師需要付薪資（依關係打折）

## 九、戰鬥系統

### 行動延遲系統（CTB變體）
- 每個角色頭部旁邊有一條行動條（放在側邊列表，附大頭照）。
- 行動條顯示值 = 目前行動延遲 / 100；顯示最多為滿條，但行動延遲本身可超過 100 並繼續累積。
- 做動作、受到硬直、或承受延遲效果時，增加對應的**實際行動延遲數值**；恢復與加速效果則直接減少實際數值。
- 反應屬性影響動作增加的行動延遲（反應高→增加較少→行動更快）。
- 列表依剩餘行動延遲排序；剩餘越少的角色排越前。

### 狀態顏色
- 白色：正常讀條
- 黃色：施法/演奏中（可被打斷）
- 藍色：格擋狀態中
- 紅色：硬直/被擊退
- 灰色：昏迷/無法行動

### 狀態對行動延遲的影響
- 中狀態：直接增加行動延遲。
- 恢復狀態：直接減少行動延遲。
- 行動延遲超過 100 仍繼續累積，因此疊加硬直仍有意義；行動條只顯示為滿。

### 戰鬥行為（四種）
1. **9宮格技能盤**（選技能自動切換對應武器組）
2. **指揮隊友**
3. **休息**（恢復疲勞值，回復少量生命與魔力）
4. **逃跑**

- **沒有普通攻擊**：任何攻擊、格擋、施法、演奏、移動或支援行為，都必須由玩家選擇技能執行。
- 每個技能有內部分類資料：啟動手別、武器需求、行為類型與技術分類；玩家介面只顯示必要的需求與類型。

### 雙方九宮格與敵人體型

- 戰鬥雙方各自使用一個 **3×3 九宮格**；站位、技能範圍與佔用均在各自陣地內判定。
- 小型敵人與人類敵人佔 **1×1**；中型敵人佔 **2×2**；大型敵人佔 **3×3**。大型敵人會占滿其陣地，不能與其他敵人同場佔格。
- 體型與威脅等級分離：一般、菁英、BOSS 都是威脅等級；小型、中型、大型都是佔格尺寸。唯一硬規則是 **BOSS 必為大型（3×3）**。

### 反擊與裝備效果（第一版）
- 反擊技為「主動建立、條件結算」：玩家先選擇反擊技並進入藍色格擋架勢；在架勢期間成功格擋符合條件的近戰技能時，才立即結算反擊。
- 反擊不是常駐被動。條件未發生、格擋失敗或角色被硬直時，不會自動出手。
- 裝備效果以常駐係數、技能分類觸發、特定技能觸發、狀態／事件觸發四層設計；一般裝備優先使用技能分類觸發，具名技能觸發保留給高品級裝備。
- 雙持時，主手／副手技能只觸發對應手的裝備效果；雙手同時技能可分別判定兩手效果，但相同控制效果不疊加，只取最強者。
- 盾牌常駐防護在持有時有效；盾擊、掩護等效果只由盾牌技能觸發。

### 武器配置（3組）
```
手 手 ＋ 技能 技能 技能
手 手 ＋ 技能 技能 技能
手 手 ＋ 技能 技能 技能
```
- 每組：主手＋副手＋三個對應技能
- 選同組技能不換裝，跨組選技能付切裝延遲
- 雙持：同組內可混搭兩種武器的技能，無需切裝，但副屬性打折

### 隊友AI
- 隊友自行行動
- 玩家可下達指令要求隊友做特定事情

## 十、疲勞系統

### 兩層疲勞
**戰鬥中（短期/肌肉缺氧）**
- 從基礎值開始
- 行動、受傷會增加
- 靠藥水、食物、音樂、增益魔法、休息即時調整
- 無論怎麼恢復，不能低於基礎值

**戰鬥外（長期/身體狀態）**
- 就是基礎值本身
- 地城內：走地格、經歷戰鬥會提升；可在地城內休息（效果差）
- 地城外：城市間移動、戰鬥會提升；靠旅館/家裡休息或用餐恢復

### 疲勞滿百的後果
**地城內昏迷：**
- 可能被偷東西
- 可能被傷害
- 消耗一定時間後醒來，恢復一定量基礎值

**地城外昏迷：**
- 消耗掉整整一天
- 基礎值回到60（不是完全恢復）
- 同樣可能被偷東西或被傷害

## 十一、人口系統

### 冒險者補充
- 採用暴力補齊機制，定期補充新冒險者
- 補齊數量與城市繁榮度/安全度掛鉤
- 惡意殺人有獨立懲罰機制（懸賞/通緝），不依賴人口減少來懲罰玩家

## 十二、城市與國度系統

### 國度設定
- 幾個不同特色的國度
- 每個國度商品完全不同（補血藥、照明道具、武器裝備等）
- 國度間有通行證制度

### 戰爭機制
- 兩個國度接壤，力量對比懸殊時有機率觸發戰爭
- 對玩家的影響：
  - 物價指數變動
  - 事件發生權重改變
  - 通行證可能失效（突然無法進入某個國度）

### 城市間移動
- 馬車移動動畫
- 移動過程中世界照常運算
- 長途移動累積疲勞基礎值
