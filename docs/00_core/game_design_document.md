# 遊戲基礎設計文件
> 靈感來源：俠客遊（Lunatic Dawn）系列，重新設計

---

## 核心哲學

**世界內容先於一切。**

地圖與城市先生成客觀存在的內容：物品、怪物、綁架／控制狀態、大怪與店家庫存。NPC、城市居民與組織得知或受其影響後，才產生事件、情報、收購或委託；委託不是內容的起點。

玩家沒有固定目標，扮演一名冒險者，靠接委託維生、提升自己，一直到角色老死為止。角色死亡後可繼承隊友、子女或家人繼續遊戲。

## 一、世界模擬系統

### 時間推進
- 採用「玩家行動觸發＋批次結算」模式
- 玩家做了耗時動作（旅行、睡覺、進地城）才觸發世界往前結算
- 不是24小時空轉的即時模擬引擎

### 新遊戲初始化

- 開始新遊戲時，先一次完成內容驗證、世界／城市／地圖、玩家角色與隊伍、初始冒險者、商店／庫存及第一批排程的建立。
- 初始化全部成功後才正式進入第一個遊戲頁面；失敗時停留在初始化錯誤畫面，不產生可遊玩的半成品世界。
- 這是一次性的開局流程，不屬於每日結算或遊戲內行動。

### NPC模型
一般背景 NPC 的世界反應只需要四個維度：
- 身份標籤（商人、衛兵、冒險者、平民等）
- 已知世界內容與對其的反應（想取得、想處理、無反應）
- 所在位置與可及範圍
- 簡易關係表（只記「跟誰有未了結的事」）

上述關係表不是好感網路。遊戲不保存 NPC 對 NPC 的好感，也不保存所有角色兩兩關係；每名真實冒險者只額外有一個「對玩家」好感值。

真實冒險者另有完整角色、熟練度、隊伍行動、個人帳戶與個人物品資料；護衛等匿名任務人物則只在接取後建立暫時角色，不套用完整資產模擬。護衛角色只附屬於 Quest，不加入護送隊伍、不占正式人數或戰鬥格位。

### 隊伍與個人資產

- 隊伍只是共同移動與共同決定大動作的行動共同體；沒有一般共用金庫或共用背包。
- 一支玩家或 NPC 冒險隊伍固定為 1～9 名正式成員。所有正式成員都是出戰者，必須全部配置在己方 3×3；沒有候補、預備隊或第十名成員。
- 每名正式冒險者各自擁有金錢、背包、裝備與其他一般物品。招募、解雇、換隊或成為隊長都不會轉移其個人資產。
- 所有物品都有固定重量。角色攜帶採用**重量上限**而非格子上限；上限由肌力依資料規則計算，背包與已裝備物皆計入。住家倉庫、商店、地圖內容與結算暫存不計入角色攜帶重量。
- 任務物資雖不屬於角色財產，仍須指定一名正式隊員作為實際攜帶者，並計入該角色的重量上限。
- 只有「隊伍任務物資空間」是以 Team ID 管理的特殊鎖定區；它是任務保管，不是財產所有權。
- 任務金錢與地牢最後形成的可分割現金平均分給該次參與者；實體物品則必須先分配到某個角色，不能留成隊伍共有物。
- 任何狀態變更使玩家隊角色超過重量上限時，立即進入強制超載處理畫面。玩家只能將物品送給仍有容量的隊友、在目前城市且擁有房屋時移入倉庫，或遺棄物品；全隊所有超載角色回到上限內以前不得關閉畫面或執行其他行動。旅行途中不開啟此畫面，抵達後才處理延後檢查。

### 世界內容與事件生成邏輯
- 地圖刷新與城市庫存先生成世界內容；內容本身可維持未被發現、未被需要的狀態。
- 角色、居民或組織得知內容後，依固定反應規則決定是否形成事件、情報或委託，而不是先隨機生成需求。
- 分層精細度：背景層（純統計）、在地層（簡單反應）、互動層（完整模擬）。

### 事件外溢
世界內容被得知後分流到下游系統：
- 成為地圖事件或酒館情報嗎？
- 依反應規則產生委託嗎？
- 更新 NPC 關係表或城市狀態嗎？

## 二、事件系統

### 目前確定的反應規則
- 迷宮生成怪物類內容後，當地居民 100% 於當地冒險者公會發布處理該地的委託。
- 迷宮生成綁架類內容後，隨機一座城市 100% 於其冒險者公會發布救援委託。
- 迷宮或城市庫存生成物品後，才依機率決定是否有人委託取得它；未形成委託的物品可維持原處，並可成為酒館打聽到的情報。

### 事件與地圖的關係
- 事件可在地圖上增加目標、佔據狀態或特殊報酬，但不是城市、可探險地與一般怪物內容的必要來源。
- 地城的特殊「當下狀態」可被玩家消耗（清完、拿完就沒了）；新特殊狀態由新事件觸發，不是定時刷新。
- 玩家透過打聽消息得知地圖發生了什麼

## 三、委託系統

### 核心原則
- 委託不是內容入口，而是既存世界內容被正式處理的一種包裝。
- 不是所有世界內容都會形成委託；物品尤其可能只作為可打聽、可探索的情報存在。
- 玩家可以完全不靠委託板，自己撞見同一個事件
- 打死龍但沒接鎮壓委託，一樣有歡呼，但沒有正式獎勵
- 所有獎勵與任務熟練度都必須回到**接取該任務的冒險者公會**結案後才發放；在目的地達成條件只會讓任務進入「完成」，不是最終成功。
- 任務金錢報酬由接取當下的正式隊員平均分配；護衛角色不屬於隊伍，救援等任務暫時角色也不參與分配。

### 委託類型
- **購買**：取得指定物品並交付委託人。
- **送貨**：將指定物品從 A 地送至 B 地。
- **護衛**：將指定人物從 A 地帶至 B 地。
- **救援**：前往冒險點，找到並救出指定人物。
- **探索**：前往冒險點，尋找並帶回指定物品。
- **鎮壓**：將指定冒險點內的所有怪物清除。
- **討伐**：將指定冒險點內的所有大怪清除。

每張委託在生成時固定一種類型。鎮壓與討伐的目標狀態在生成時固定，並以三期刷新鎖維持至結束。

### 委託狀態與結案

委託只使用四種狀態：

| 狀態 | 定義 |
|---|---|
| 未接取 | 可在接受期限前由公會接取。 |
| 未完成 | 已接取，但尚未達成任務條件。 |
| 完成 | 已達成條件，尚未回到接取公會結案。 |
| 到期 | 已不可能獲得任務報酬與熟練度的終止狀態；不另設「失敗」狀態。 |

- 接受期限到達時，仍為未接取的任務轉為到期並從公會撤下。
- 實際結束期限到達時，任何尚未在接取公會結案的任務都轉為到期；即使狀態已是完成也不例外。
- 完成任務後，必須在實際結束期限前回到**原接取公會**結案，才取得報酬與該類型任務熟練度；結案後從任務清單移除。

### 各類任務的完成與到期條件

| 類型 | 轉為完成 | 轉為到期／終止 |
|---|---|---|
| 護衛 | 進入目的地城市時，自動觸發護衛對象感謝對話。 | 對象死亡、護送隊伍在抵達前任一場 detailed 戰鬥或簡易戰鬥節點戰敗，或實際結束期限到達。 |
| 送貨 | 進入目的地指定設施時，自動交付貨物。 | 實際結束期限到達。 |
| 購買、探索 | 指定實體物件進入該任務的「隊伍任務物資空間」時。 | 實際結束期限到達。 |
| 鎮壓 | 殺死指定地圖最後一隻怪物時。 | 實際結束期限到達。 |
| 討伐 | 殺死指定大怪時。 | 實際結束期限到達。 |
| 救援 | 救到指定人物且離開該地圖時。 | 實際結束期限到達。 |

### 隊伍任務物資空間

- 隊伍有一個只服務任務的特殊鎖定區；它不是一般共享背包，也不代表隊伍擁有該物品。
- 購買、送貨、探索任務的指定實體一旦取得，就直接鎖入對應任務的物資空間；不可使用、裝備、出售或一般轉移，只能交付該任務。
- 強制超載處理是唯一例外：任務物只能改派同隊正式攜帶者，不能入房屋或轉為個人財產；若玩家選擇遺棄，該實體永久移除且任務失去可完成目標，但仍維持既有四狀態並於期限到達時轉為到期。
- 購買任務由實際付款角色的個人帳戶扣款，但指定物不會先成為付款者私產。
- 送貨抵達指定設施時直接從物資空間交付回收；購買與探索物則留在物資空間，直到回原公會結案時交付回收。
- 已接取任務到期後，仍鎖在物資空間的物品才解除任務限制並分給接取時的正式隊員：玩家隊逐件內部競拍，NPC 隊逐件隨機分配。
- 任務狀態仍只叫「到期」而非「失敗」；「任務失敗後釋放物資」在規則上就是進入到期狀態後處理。

### 委託來源
- 只有非冒險者角色可以發委託
- 冒險者（含玩家）負責接委託

### 護衛委託的生成

- 護衛對象固定為非冒險者，不從既有冒險者 NPC 或迷宮事件推導；生成資料僅有身分原型，例如富商、貴族等，沒有名字，也不是世界中持續活動的真實 NPC。平民不進入護衛候選池。
- 每座城市各自分配一個 0～6 日的週期偏移；每 7 日只在自己的固定日結算一次護衛候選，避免所有城市在同一天生成與運算。
- 每次結算隨機產生 0～5 名想移動的非冒險者；目前 `5` 是基礎上限，日後可由城市、事件或世界因素修改。
- 每名生成者後續成為該城可發布的護衛內容。接取任務時才生成與該 Quest 綁定的暫時 NPC；它不加入 Team、不占正式人數、不進九宮格也不參戰，位置只跟隨護送隊伍推導。抵達目的地、該 NPC 死亡、護送隊伍任一戰敗，或任務到期未送達時均回收。到期未送達時，NPC 先表達「太失望了」後回收。
- 只有玩家隊伍持有至少一筆進行中的護衛任務時，「護衛刺殺」才會成為玩家旅行事件池的合法候選；事件抽中時固定其中一筆護衛任務作為敘事對象。非玩家隊伍沒有旅行事件池，因此接取護衛任務也不會抽刺殺事件。
- 一支隊伍可以同時持有多筆護衛委託；在護送過程中只要發生一次戰敗，該隊所有仍為「未完成」的護衛委託都立即轉為「到期」，不影響已經送達而進入「完成」的護衛委託。任務仍不新增第五種「失敗」狀態。
- 目的地選擇、接受期限與實際結束期限尚未定義，不自行假設。

## 四、地城系統

### 地圖結構
- 每個可探險地先定義地圖模板，而不是先定義怪物或事件。
- **野外**固定為單層 8×8 格；可部署、遭遇與探索都在同一層完成。
- **內部地圖**的每層為 4×4 或 5×5 格。洞穴通常由地上一層向下延伸，最多至地下三層；塔可由地上最多三層與地下最多三層組合。除野外外，實際要使用幾層可依地點自由決定。
- **國家迷宮**另用較大的模板：野外型固定 10×10；非野外型固定 6×6。地牢型固定為地上 1 層、地下 5 層；建築型固定為地上 4 層、地下 2 層。
- 格子與格子之間必須有通道或紅門才能通行；兩者皆無即為不可通過的空間。通道與紅門的位置屬於固定模板資料。
- 連接兩層的樓梯必須使用相同的列、行座標：上層的 `↓` 與下層的 `↑` 永遠落在同一格。小地圖因此能正確顯示垂直關係，也可設計同層看得到卻必須經下層繞行才能到達的區域。
- 相鄰的小格之間若沒有牆線，代表它們是同一個房間的合併格，不是通道縫隙；房間可以是 L、T、凹形等任意形狀，不必限制為 1×1。
- 每個合併房間才是一個可選擇的移動節點。玩家只在房間與房間之間移動，房內沒有逐格移動行為；但系統會記錄角色進入房間的小格座標，並依此座標到下一個離開連接點的房內最短實際路徑，結算迷宮時間。
- 樓梯、陷阱、固定採集點、寶箱／事件／大型敵人偏好等皆附屬於房間；圖上的圖示座標只用於辨識與小地圖對齊，不另形成一個可移動格。
- **入口、出口、樓梯與固定陷阱**是互斥的單格功能房間，必須各自獨立為 1×1；其中不可生成怪物、寶箱或事件，也不可與另一種功能共用房間。
- 每個探索地圖合計配置 **1～3 個出口**；出口可位於不同樓層，但皆計入同一探索地圖的出口數。
- 房間、牆壁、通道、門與陷阱位置固定；陷阱類型固定，僅啟用、解除或觸發後的狀態會改變。
- 採集點的位置與資源規則屬固定模板；一個採集點占用該房間唯一的內容槽，不能再與怪物、Boss、寶箱、救援人物或其他事件共存。同一房間至多一個採集點。
- 模板可標記偏好格，例如寶箱／儲物格、大型敵人格、綁架／囚禁格、伏擊格等；寶物、大型敵人與事件依標記放置。大型敵人格必須位於長、寬皆至少 2 格的大房間；事件偏好格至少位於由 2 格以上組成的中型房間。一般怪物沒有偏好格，可生成於任一可通行且允許生成的普通格。
- 玩家探索過會記錄小地圖，**跨場保留**
- 陷阱屬於空間知識的一部分，走過就知道

### 內容機制
- 每個可探險地有固定的「所在地文化」產物與非人類怪物池；怪物池只依文化區分，不依城市或個別探索地細分；不需要先有事件才會成為基本探索內容。
- 人類敵人另讀取「目前佔領國」的文化池；地點被他國佔領後，當地物品與非人類怪物不變，只有人類敵人的武器、裝備、技能與外觀改變。
- 所有敵對遭遇以擊殺結束；不設投降、談判或逃離的戰鬥結算分支。
- 物品、怪物與事件皆為動態內容；生成時依地圖模板的偏好格放置。事件只額外改變目標、數量、特殊佔據者或報酬，不取代地點本身的產物與怪物池。
- 固定採集點在每個地圖版本只能成功採集一次，正式刷新後恢復可採。揭露過房間後永久記得採集點位置，但是否可採仍以目前版本狀態為準。
- 採集時自動使用本次探索正式參與者中採集等級最高者；同級以穩定角色 ID 決定。該角色等級決定產物種類與數量，且只有該角色取得一次採集 MXP。
- 地牢採集會消耗資料指定的正數迷宮分鐘；精確值由採集 Rule 定義。產物視為共同探索成果，先進入本次戰利品空間，離場時仍採玩家競拍／NPC RNG 分配，不直接歸採集者。
- 玩家隊離開地牢前處理共同戰利品：每件物品以原價值作為最低出價進行隊內競拍；無人要的物品按原價值 80% 直售。競拍款、直售款與地牢金幣合併後，由進入本次探索時的正式隊員平均分配。
- NPC 隊不模擬競拍；每件物品以 RNG 分給一名本次正式參與者，可分割金錢仍平均分配。戰利品分配完成後才算結束地牢行動。
- 每張探索地圖固定每 14 日刷新一次；地圖各自分配一個 0～13 日的刷新偏移，因此世界每天只處理其中一批地圖，不會在同一天大量刷新。
- 刷新日若有任一冒險者仍在迷宮內，該地圖設為 `Pending Refresh`。最後一名冒險者離開時只登記下一日的 Pending 檢查；次日仍無冒險者且未被鎖定時才刷新並清除 Pending。它不改變原本的固定刷新日，也不累積為多次刷新。
- 討伐與鎮壓在生成時就使對應地圖進入三期減一天（41 日）的刷新鎖；不論委託是否被接取，期間皆跳過刷新日且不建立 Pending。鎖定在下一個應刷新日前一天解除，因此隔天可自然刷新；不補算、不累積。
- 每份委託在生成時固定寫入兩個絕對日期：**接受期限**限制它何時以前能在公會被接取；**實際結束期限**是內容與委託最終結束的世界日期。接取不會延後實際結束期限。
- 城市距離一律以城市網路的最短「相隔城市數」計算；每跨一個城市隨機抽取 9～15 日，並在委託生成時固定寫入期限。送貨與購買的接受期限為生成後 14 日，實際結束期限為生成後 `14 日 + 各城市距離格的 9～15 日總和`；兩者最多相隔 2 個城市。救援與探索的接受期限為生成後 7 日，實際結束期限為生成後 `7 日 + 各城市距離格的 9～15 日總和`。
- 庫存類委託未在接受期限前接取時，指定實體道具直接消失。送貨接取時，指定物進入任務物資空間，抵達指定設施後立即交付回收；購買與探索指定物在取得後進入任務物資空間，回原公會結案才交付回收。任何已接取任務到期時仍留在物資空間的物品，都解除任務鎖並進入全隊分配，不會回到永久庫存或商店。
- 迷宮救援類委託未在接受期限前接取時，綁定元素直接消失；已接取時，綁定人物、控制者與必要場景在實際結束期限前會跨刷新保留。實際結束期限到達仍未結案時，任務轉為到期，這些元素才可在後續刷新中移除。

### 一天的結構
- 城內買賣、聊天、接／交委託與冒險者互動不消耗時間。
- 玩家隊伍的城市間移動有趕路 3 日、正常 6 日、慢行 9 日三種選擇。每趟固定切成前、中、後三段，每段結束各骰一次玩家旅行事件；事件 Actor 固定為目前玩家主角，隊友不各自抽取。三種模式分別採 1／1／1、2／2／2、3／3／3 日的三段長度。趕路提高負面事件權重且旅行經驗 ×0.5；正常採基準權重與旅行經驗 ×1；慢行提高正面事件權重且旅行經驗 ×2。
- 所有非玩家隊伍的城市間移動固定為 6 日，沒有前／中／後段落、旅行事件池、事件骰、事件互動或刺殺事件。第 6 日直接抵達，旅行經驗每趟發一次且倍率固定 ×1；不得實作成先抽事件再自動略過。
- 城市前往其對應冒險點固定消耗 1 日；離開冒險點返回城市也固定消耗 1 日，不處理半日出地牢的特殊切分。
- 住宿至少消耗 1 日；製造一件物品至少消耗 1 日；熟練度傳授／訓練每次消耗 28 日。技能不屬於可傳授內容。
- 個人製作、鍛鍊與傳授使用「所需自由日數」倒扣。離開城市自由活動只會凍結剩餘日數；下一段自由活動繼續扣除同一件事，直到歸零才結算結果並抽取下一件自由行動。不存在因單次自由期太短而取消、重抽或從頭計時。
- 在家休息一年消耗 365 日，主要用途為取得生育機率。
- 地城以迷宮分鐘處理：每經過 1 個實際小格消耗 30 分鐘；戰鬥本身不消耗迷宮分鐘。完整規則見 [時間、迷宮與熟練度原則](../02_systems/time_and_mastery_progression.md)。

## 五、成長系統

### 主屬性（五項）
| 屬性 | 說明 |
|------|------|
| 肌力 | 力量、爆發力、承受衝擊 |
| 智力 | 魔法、學習、預判 |
| 反應 | 速度、感知、即時判斷 |
| 協調 | 精準度、靈活度、力量傳遞效率 |
| 魅力 | 社交影響力（熟練度＋聲望合成） |

主屬性由**熟練度的累積**帶動成長，每種熟練度對應不同的主屬性成長比例。

- 五項主屬各自上限為 100；滿值後的熟練度成長不轉換為其他屬性。
- 熟練度採 Lv.0～Lv.10；玩家不能自行配主屬點，每一級的增加內容由固定成長表決定。
- 單項熟練度的主屬總成長曲線與時間原則，見 [時間、迷宮與熟練度原則](../02_systems/time_and_mastery_progression.md)；第一版經驗數值見 [熟練度經驗經濟 v1](../02_systems/mastery_experience_economy_v1.md)。

### 聲望
- 獨立系統，同時作為魅力的輸入之一
- 影響委託機會、NPC態度、能招募的冒險者品質

### 副屬性
由「主屬性×武器/防具配方×熟練度係數」合成：

**物理系**
- 物理傷害
- 命中
- 迴避
- 預判
- 格擋
- 一般減傷
- 格擋減傷

**魔法系**
- 魔法傷害
- 魔法命中
- 魔法減傷

**樂器系**
- 樂器傷害（絕對命中、不吃一般減傷）
- 樂器減傷（頭盔重量＋年紀決定）

### 副屬性公式
```
副屬性 = (主屬性 × 武器/防具權重配方) × 持握係數 × 熟練度係數
```

**持握係數：**
- 單手持握 / 雙手持握：× 1.0
- 雙持左手：× 0.5
- 雙持右手：× 0.35
- 雙持總輸出 = 左手結果 + 右手結果

### 副屬性對應主屬性
| 副屬性 | 主屬性組合 |
|--------|-----------|
| 物理傷害 | 肌力＋協調 |
| 魔法傷害 | 智力 |
| 命中 | 反應＋協調＋智力 |
| 迴避 | 反應＋協調＋智力 |
| 預判 | 智力＋反應 |
| 格擋成功率 | 反應＋協調 |
| 格擋吸收 | 肌力 |
| 一般減傷 | 肌力＋防具 |
| 魔法減傷 | 智力＋魔法熟練度＋裝備 |
| 移動速度 | 肌力＋協調 |
| 生命值 | 肌力 |
| 樂器減傷 | 頭盔重量＋年紀 |

### 招式系統
- 技能（包含魔法）與熟練度經驗分開處理；熟練度門檻只決定角色是否具備取得／學習該技能的資格。

- 其餘技能，以及鍛造、裁縫、製藥等製作內容，必須透過對應書籍學習。所有書籍共分三級：**基礎書籍**由書店販售，**高級書籍**只能在探索中取得，**極品書籍**只由 BOSS 掉落；三種書籍都必須符合指定熟練度門檻才能學習。
- 技能無法由角色、教師或訓練所傳授；28 日傳授只增加同項熟練度的經驗，不會直接給予技能。
- 技能與招式沒有獨立熟練度；技能造成的成長只會進入既有熟練度，技能本身只處理取得資格、裝備需求與效果資料。

## 九、戰鬥系統

### 倒扣式 CTB
- 每個角色頭部旁邊有一條行動條（放在側邊列表，附大頭照）。
- 開場時敵我所有單位使用相同的開場 CTB 基礎值，再分別扣除資料指定的主屬減免。
- 每輪推進找出目前最小 CTB，所有單位一起扣掉該數值；扣到 0 的單位可以執行動作。
- 多名單位同時到 0 時，我方單位先於敵方單位；同一側同值時隨機排序，不再追加其他屬性判定。
- 行動條顯示值 = 目前 CTB / 100；顯示最多為滿條，但目前 CTB 本身可超過 100。
- 做動作、受到硬直、或承受延遲效果時，增加對應的**實際 CTB 數值**；恢復與加速效果則直接減少實際數值，最低為 0。
- 反應屬性可依各動作的資料規則減少動作增加的 CTB；實際係數與最低值不寫死在程式內。
- 所有已到 0 的單位處理完後，才再次找最小值並進行下一次全體倒扣。

### 狀態顏色
- 白色：正常讀條
- 黃色：施法/演奏中（可被打斷）
- 藍色：格擋狀態中
- 紅色：硬直／CTB 延後
- 灰色：昏迷/無法行動

### 狀態對 CTB 的影響
- 延遲狀態：直接增加目前 CTB。
- 恢復／加速狀態：直接減少目前 CTB，最低為 0。
- 目前 CTB 超過 100 仍繼續累積，因此疊加硬直仍有意義；行動條只顯示為滿。

### 戰鬥行為（四種）
1. **9宮格技能盤**（選技能自動切換對應武器組）
2. **戰鬥道具**
3. **指揮隊友**
4. **休息**（回復少量生命與魔力）

- **沒有普通攻擊**：任何攻擊、格擋、施法、演奏或支援行為，都必須由玩家選擇技能執行。
- **沒有戰鬥移動**：玩家、AI、技能與狀態皆不能自主換格、推拉或擊退。
- 每個技能有內部分類資料：啟動手別、武器需求、行為類型與技術分類；玩家介面只顯示必要的需求與類型。

### 詳細戰鬥與簡易戰鬥串

- 玩家正常戰鬥走 detailed Encounter，依真實傷害、初始站位與無傷害技能的實際成功使用次數取得熟練經驗。
- 掃蕩不建立九宮格或抽象 Encounter，而是建立 Combat Sequence；一般戰鬥掃蕩是一節點，地牢掃蕩則把地牢中的怪物內容依順序組成多節點戰鬥串。
- 每個簡易節點只以固定隊伍戰力對敵方戰力擲骰，不計 HP、傷勢、逐招行為或戰後戰力損耗。戰力相對差在 15% 內時，失敗可依資料規則消耗補品重骰。
- 戰鬥串在全清、首次失敗或來源要求停止後一次結算：正式成功節點的攻擊／防禦經驗加總後分配，無傷害技能按正式成功場次計算。NPC 地牢與未來玩家掃蕩使用相同規則。

### 雙方九宮格與敵人體型

- 戰鬥雙方各自使用一個 **3×3 九宮格**；站位、技能範圍與佔用均在各自陣地內判定。
- 隊伍持有一份可配置的開場九宮格；全部 1～9 名正式成員都必須恰好配置一次，沒有候補。Encounter 開始時讀取快照，戰鬥中的自動補位不寫回原配置。
- 一側第 1 排仍有任何占格單位時，第 2、3 排完全不前移。第 1 排全空後，該側最前方仍有人的排數會補到第 1 排，後方各排同步前移相同排數並保留欄位與相對排距。
- 開場若第 1 排原本就是空的，立即執行同一套補位；一個完整動作與反應鏈結束後才再次判定，多段技能中途不補位。
- 暫時昏迷或無法行動的單位仍占格；只有死亡並移出該格後，才可能觸發前排全空判定。
- 小型敵人與人類敵人佔 **1×1**；中型敵人佔 **2×2**；大型敵人佔 **3×3**。大型敵人會占滿其陣地，不能與其他敵人同場佔格。
- 體型與威脅等級分離：一般、菁英、BOSS 都是威脅等級；小型、中型、大型都是佔格尺寸。唯一硬規則是 **BOSS 必為大型（3×3）**。
- 地圖生成與熟練度試算的基本單位是「遭遇戰」，不是單隻敵人。低階小型怪物的群體遭遇通常會以同種小怪填滿或接近填滿敵方 3×3 陣地（8～9 隻）；這類數量不代表同一時間只會有一隻普通怪。

### 反擊與裝備效果（第一版）
- 反擊技為「主動建立、條件結算」：玩家先選擇反擊技並進入藍色格擋架勢；在架勢期間成功格擋符合條件的近戰技能時，才立即結算反擊。
- 反擊不是常駐被動。條件未發生、格擋失敗或角色被硬直時，不會自動出手。
- 裝備效果以常駐係數、技能分類觸發、特定技能觸發、狀態／事件觸發四層設計；一般裝備優先使用技能分類觸發，具名技能觸發保留給高品級裝備。
- 雙持時，主手／副手技能只觸發對應手的裝備效果；雙手同時技能可分別判定兩手效果，但相同控制效果不疊加，只取最強者。
- 盾牌常駐防護在持有時有效；盾擊、掩護等效果只由盾牌技能觸發。

### 武器配置（3組）
```
手 手 ＋ 技能 技能 技能
手 手 ＋ 技能 技能 技能
手 手 ＋ 技能 技能 技能
```
- 每組：主手＋副手＋三個對應技能
- 選同組技能不換裝，跨組選技能付切裝延遲
- 雙持：同組內可混搭兩種武器的技能，無需切裝，但副屬性打折

### 隊友AI
- 隊友自行行動
- 玩家可下達指令要求隊友做特定事情

## 十、恢復與暫時狀態

- **不使用額外的體力／耐力資源**：移動、戰鬥、旅行與製造不另設會累積、消耗或導致昏迷的長短期資源。
- 角色的可恢復狀態由生命、魔力與暫時狀態組成；暫時狀態的具體清單（如流血、恐懼、昏沉）由技能、道具、事件與地圖陷阱分別定義。
- 旅館以「恢復狀態」為唯一定位：住宿至少 1 日，恢復生命、魔力，以及可由休息解除的暫時狀態。
- 家中休息也可恢復狀態；休息一年另具取得生育機率的用途。
- 戰鬥與地城的風險改由生命、魔力、CTB、暫時狀態、固定陷阱與事件承擔。

## 十二、城市與國度系統

### 城市固定功能（第一版）

所有城市使用同一組功能場所；城市差異由商品、基礎書籍目錄、教師、可互動 NPC、情報、委託與對應冒險點形成，而不是再增加專屬的系統建築。

| 場所 | 功能 |
|---|---|
| 旅館 | 住宿至少 1 日，恢復生命、魔力與可由休息解除的暫時狀態。 |
| 酒館 | 探聽情報、遇見與互動冒險者。 |
| 冒險者公會 | 接取與交付委託。 |
| 道具店 | 買賣道具、提供相關製作環境與生活熟練度訓練。 |
| 裝備店 | 買賣裝備、提供鍛造／裁縫相關製作環境與熟練度訓練。 |
| 訓練所 | 提供戰鬥與魔法熟練度訓練；不傳授技能。 |
| 書店 | 販售技能與鍛造／製作內容的基礎書籍；購得後仍須符合指定熟練度門檻才能學習。高級書與極品書不會進入販售池。 |
| 冒險者關卡 | 前往或返回本城對應的冒險地圖。 |
| 城門口 | 選擇趕路、正常或慢行前往其他城市。 |
| 家 | 家族、子女教育、熟練度傳授、休息與休息一年。 |

- 第一版先保留房屋所有權、倉庫、休息／生育、傳授與繼承入口；房間形狀、家具安放、功能間容量與升級規則屬獨立大議題，尚未定案，不由目前的簡化 Slot 骨架反推玩法。
- 書店不提供技能傳授，也不以書籍取代熟練度門檻；它只提供可購買的基礎書籍。高級書只在探索中取得，極品書只由 BOSS 掉落。
- 城市裡的 28 日訓練與家中的傳授只改變熟練度 MXP，不能取得或補強技能。
- 七項生活技藝都可在城鎮內的對應建築接受 28 日訓練；城鎮教師的對應熟練度固定為 Lv.5。
- 每一次 28 日傳授／訓練都套用單次跨級上限：從起始等級 `N` 出發，結果最多停在 `N+1` 的 99.99%（內部值為進入 `N+2` 的門檻減 1）；即使原始可得經驗足以跨至 `N+2` 以上也不例外。Lv.10 則以熟練度最大值為上限。

### 酒館冒險者、招募與解雇

- 酒館遇到的是世界中真實存在、目前在該城酒館活動的冒險者，不是臨時生成的人物卡。
- 所有酒館冒險者都可以聊天；聊天內容直接說明其目前或最近完成的真實行動，不另外 RNG 捏造經歷。聊天不消耗時間。
- 玩家隊長可以嘗試招募酒館冒險者，但不會直接成功。目標必須是單人 NPC Team、玩家隊尚未滿 9 人，並通過資料化招募機率檢定；交流熟練度的邀請加成必須進入該檢定。只有成功時目標才轉入玩家隊伍，個人金錢、背包、裝備與物品完全不變。最終公式與再次嘗試間隔另行定案。
- 隊長可以解雇非隊長正式成員；解雇立即完成且不消耗時間，被解雇者在相同位置成為 NPC 行動單位。
- 任務暫時角色不能被招募、解雇成獨立冒險者，也不參與一般報酬與戰利品分配。

### 隊員交流、好感與婚姻

- 每名非玩家真實冒險者只有一個對玩家的好感值；沒有 NPC 對 NPC 的好感、關係矩陣或對話歷史網路。
- 玩家可在沒有戰鬥／強制互動阻塞時，隨時從正式隊員的互動畫面選擇「交流」；不要求位於酒館且不消耗世界時間。隊員交流、酒館聊天與打聽情報共用玩家每日最多 6 次對話。
- 伴侶只能從玩家隊伍內成年、存活、未婚且與玩家異性的正式成員中產生。符合條件時互動畫面提供「求婚」；接受依目標對玩家的好感判定，不靠重複零時間洗 RNG。
- 非玩家冒險者的個人自由行動可抽到向同隊未婚異性正式成員求婚。NPC 彼此不使用好感度；只用共隊天數、雙方戰力接近程度與一次資料化機率判定。玩家主角不能成為這條自動求婚流程的目標。
- 成功婚姻只建立一條正式伴侶關係，不自動改隊、轉移資產、換住處或取消既有工作。每人同時最多一名伴侶。
- 冒險者對玩家的好感可修正其受邀擔任家教的價格；實際修正曲線由資料決定。

### 國度設定
- 幾個不同特色的國度
- 每個國度商品完全不同（補血藥、照明道具、武器裝備等）
- 國度間有通行證制度

### 戰爭機制
- 兩個國度接壤，力量對比懸殊時有機率觸發戰爭
- 對玩家的影響：
  - 物價指數變動
  - 事件發生權重改變
  - 通行證可能失效（突然無法進入某個國度）

### 城市間移動
- 馬車移動動畫
- 移動過程中世界照常運算
- 玩家隊伍每趟移動固定分為前、中、後三段；每段結束各處理一次旅行事件。三種旅行模式的日數、事件權重與旅行經驗倍率，依「一天的結構」執行。
- 非玩家隊伍固定 6 日直達，不建立旅行段落或事件；它們的旅程只參與世界時間與抵達結算。

## 十三、尚待內容與數值調整

城市設施、事件／委託驅動、NPC 隊伍生命循環、詳細／簡易戰鬥、製作／料理、好感與婚姻等第一版系統骨架均已有正式架構契約。以下剩餘工作屬內容填充、公式調整或已明確隔離的後續議題，不代表實作者可另造系統：

- 武器、防具、怪物、技能與副屬係數的正式平衡值。
- 各熟練度的完整技能／魔法／製作書清單與解鎖門檻。
- 城市、商店、事件、委託、旅行與冒險地的實際內容池及權重。
- NPC 非自由工作、自由行動、招募、離隊、婚姻與市場選擇的數值權重。
- 製作成功率／品質曲線、消耗品產量、工藝品售價、料理詞條階級與經濟價格表。
- 好感初值與成長、玩家求婚門檻、NPC 婚姻檢定及家教價格修正。
- 子女教育、自習、教師報酬、成年轉換與第一代／後代養成速度的試算。
- 房間形狀、家具、功能間與升級規則；這是獨立後續議題，第一版現有房屋骨架只承擔所有權、倉庫、休息／生育、傳授與繼承。

第一版明確不包含疲勞、耐久／損壞／修復、易碎、真偽、贓物、犯罪、角色兩兩好感網路或技能／招式熟練度。
