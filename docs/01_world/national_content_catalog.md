> 這是裝備、道具、技能與魔法的分類資料庫；國別介紹與發想脈絡保留在 `worldbuilding.md`。
>
> **文件狀態：舊版內容與分類草稿，非現行實作資料。** 主屬性仍固定為 **肌／智／反／協／魅**；既有權重、係數與效果只保留國別方向。`../02_systems/equipment_balance.md` 同樣是歷史平衡稿，正式數值必須日後依 GDD、架構契約與 JSON Definition 重新建立。

## 共通規格

| 欄位 | 說明 |
|------|------|
| 階級 | 低階／中階／高階，分別對應初出道／成熟冒險者／資深專家。 |
| 主屬性權重 | `肌／智／反／協／魅`；`—` 表示該裝備沒有直接權重。 |
| 效果 | 只寫國別特色與戰術效果，不取代最終平衡數值。 |
